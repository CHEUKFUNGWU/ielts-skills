# 雅思写作 8.0 备考方案（诊断驱动）

核心判断：先确定瓶颈来自知识缺口、任务处理、限时控制还是系统性语言错误，再安排训练。对已经稳定在 6.5–7.0 的学习者，自动化和错误控制往往比继续收集模板更重要。

## 先诊断，再计划（永远先做这一步）

拿到用户情况（目标分 / 当前分 / 每周可投入小时数 / 最近 1–2 篇作文）后：

1. **建立准确度基线**：逐句记录总句数、无错句数和错误总数，同时标出错误是否系统性重复、是否影响理解。无错句比例是诊断指标，不等同于 GRA 档位。
2. **错误分类**：至少覆盖冠词、数与一致、动词、从句与句子边界、词序、介词与搭配、指代、标点、拼写和词形。
3. **判读**：
   - ①+② 占一半以上 → 问题可机械修正，最快见分；
   - ④ 最多 → 背单词不背搭配，改背 `{词 + 介词 + 宾语}` 整块；
   - ③ 最多 → 想写复杂句但控制不住，先退回简单句再逐周加一种结构；
   - 总句数 < 10 → 句子太长，长句是错误的主要产地，先拆短。

没有这组数字，所有计划都是猜。用户没有作文时，先安排一篇限时诊断写作。

## 8 周清零循环（Teach / Plan 模式的骨架）

```
① 写（限时 40 分钟）→ ② 自查（隔天逐句标错归类）→ ③ 归因（本周最高频 2 类）
→ ④ 针对练（改写而非重写）→ ⑤ 验证（下一篇同类型看是否减少）→ 循环
```

| 周 | 目标 | 验收标准 |
|---|---|---|
| 1 | 建立错误基线 | 数出 2 篇的错误率与类别排序 |
| 2–3 | 清零最高频的 1 类 | 该类错误连续 3 篇为 0 |
| 4–5 | 处理第 2 类 + 修正机械衔接 | 高频错误明显下降，衔接方式与逻辑匹配 |
| 6 | 固定 5–6 种"100% 写对"的复杂结构 | 全文无结构错误且句式有变化 |
| 7 | Task Response 加"第三层后果" | 每段都能说出三层逻辑链 |
| 8 | 全真模拟 20+40 分钟 | 连续 3 套表现稳定；错误偶发、不形成固定模式 |

现实约束要讲清楚：达到 8.0 所需时间因起点、反馈质量和练习稳定性差异很大，不能承诺固定课时或周期。先确认目标院校的真实要求，再决定是否把大量时间投入写作 8.0。计划中应安排可靠的外部反馈，例如老师、高水平同伴或经过复核的批改服务。

## 该背什么（用户问"背多少模板"时）

- 有证据表明整篇回答完全背诵时，官方描述符允许评为 Band 0。学习和复用词块本身不等于完全背诵，但机械套用可能损害相关性、连贯和词汇准确性。
- **常见功能位**包括改写题目、立场、主题句、解释、举例、让步、反驳、结论和限定。根据个人薄弱项准备少量可靠表达，不要求每个功能固定背 2–3 句。
- 第 2 层：可替换块（程度副词 / 连接词 / 同义动词 / 搭配）每类 8–15 个。
- 第 3 层：Points **只背论点角度不背句子**，练"把通用角度套到具体题目上"。
- 30 秒自测：抽一条论断连说三个"为什么"，说不出来 = 缺机制层，背更多模板也没用。
- 目标 6.0–6.5：功能位补齐即可；7.0：加机制层与让步反驳；7.5+：把模板用到"看不出是模板"。

## 写作 → 口语迁移（用户问"论点能不能口语用"时）

- ✅ **论点层可迁移**：写作的论点角度库对口语 Part 3 直接有效（Part 1 部分有效）；
- ⚠️ **说法层要调整**：正式连接词在口语中可换成 `so / that's why / on top of that` 等自然接续；长句通常需要拆短；`I` 在口语中很自然，但不是每句都必须使用；
- ⚠️ **Part 2 迁移有限**：部分话题词汇可以复用，但个人经历、叙事顺序和细节展开需要单独训练；
- ❌ 发音 / 流利度 / 即兴反应不在本知识库范围内，只能开口练。
