# 雅思写作 8.0 备考方案（诊断驱动）

核心判断：**8.0 的瓶颈不是"不知道什么"，而是"40 分钟里做不到"**。所以备考动作不是继续学新东西，而是把已知的东西变成不会错的自动反应——一个"错误清零循环"。

## 先诊断，再计划（永远先做这一步）

拿到用户情况（目标分 / 当前分 / 每周可投入小时数 / 最近 1–2 篇作文）后：

1. **数错误率**：逐句数出总句数、完全无错句数、错误总数——无错句比例就是 GRA 档位（band 8 ≈ 14 句里 12–13 句无错）。
2. **错误归五类**：① 冠词 ② 单复数/主谓一致 ③ 时态/动词形式 ④ 介词/搭配 ⑤ 拼写/词形。
3. **判读**：
   - ①+② 占一半以上 → 问题可机械修正，最快见分；
   - ④ 最多 → 背单词不背搭配，改背 `{词 + 介词 + 宾语}` 整块；
   - ③ 最多 → 想写复杂句但控制不住，先退回简单句再逐周加一种结构；
   - 总句数 < 10 → 句子太长，长句是错误的主要产地，先拆短。

没有这组数字，所有计划都是猜。用户没有作文时，先安排一篇限时诊断写作。

## 8 周清零循环（Teach / Plan 模式的骨架）

```
① 写（限时 40 分钟）→ ② 自查（隔天逐句标错归类）→ ③ 归因（本周最高频 2 类）
→ ④ 针对练（改写而非重写）→ ⑤ 验证（下一篇同类型看是否减少）→ 循环
```

| 周 | 目标 | 验收标准 |
|---|---|---|
| 1 | 建立错误基线 | 数出 2 篇的错误率与类别排序 |
| 2–3 | 清零最高频的 1 类 | 该类错误连续 3 篇为 0 |
| 4–5 | 清零第 2 类 + 删机械连接词 | 总错误降到每篇 ≤5 处 |
| 6 | 固定 5–6 种"100% 写对"的复杂结构 | 全文无结构错误且句式有变化 |
| 7 | Task Response 加"第三层后果" | 每段都能说出三层逻辑链 |
| 8 | 全真模拟 20+40 分钟 | 连续 3 套总错误 ≤2 处 |

现实约束要讲清楚：8.0 通常需要每周 10–15 小时、持续 2–4 个月；**总分目标 7.0、小分要求 6.5 的用户死磕写作 8.0 是资源错配**——先确认目标院校的真实要求；**没有外部反馈的 8.0 计划本质是盲练**，要安排老师 / 高水平同伴 / 批改服务补上"标错"这一环。

## 该背什么（用户问"背多少模板"时）

- 官方对"通篇背诵"给 band 0；背的语言本身不违规，违规的是整篇与题目脱钩。
- **10 个功能位**（改写题目 / 背景句 / 立场 / 主题句×2 / 机制解释 / 举例 / 让步 / 反驳 / 结论 / 对冲）各备 2–3 个变体，共 20–30 句——这是第 1 层，必须背。
- 第 2 层：可替换块（程度副词 / 连接词 / 同义动词 / 搭配）每类 8–15 个。
- 第 3 层：Points **只背论点角度不背句子**，练"把通用角度套到具体题目上"。
- 30 秒自测：抽一条论断连说三个"为什么"，说不出来 = 缺机制层，背更多模板也没用。
- 目标 6.0–6.5：功能位补齐即可；7.0：加机制层与让步反驳；7.5+：把模板用到"看不出是模板"。

## 写作 → 口语迁移（用户问"论点能不能口语用"时）

- ✅ **论点层可迁移**：写作的论点角度库对口语 Part 3 直接有效（Part 1 部分有效）；
- ⚠️ **说法层要换壳**：书面连接词（`Moreover / Furthermore / Consequently`）全部换成口语接续（`so / that's why / on top of that`）；名词化长句拆成动词化短句；主体段回避的 "I" 在口语里必须用；
- ❌ **Part 2 基本无效**：个人陈述卡需要个人经历素材，写作材料刻意避免的那部分恰好是 Part 2 唯一需要的；
- ❌ 发音 / 流利度 / 即兴反应不在本知识库范围内，只能开口练。
