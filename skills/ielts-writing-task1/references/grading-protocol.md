# Task 1 批改协议

Grade 模式的目标不是把作文改得像范文，而是判断当前表现、指出证据，并让学生知道下一篇先改什么。

## 一、先检查输入

开始评分前确认：

1. 用户参加 Academic 还是 General Training。
2. 原题是否完整。
3. Academic 图表、地图或流程图是否清晰可读；GT 的情境和三个 bullet points 是否齐全。
4. 作文是否完整，是否为限时完成。

缺少信息时不要编造：

- 没有原题或图表时，可以评 Coherence & Cohesion、Lexical Resource、Grammatical Range & Accuracy；Task Achievement 只能给条件性判断，不给确定分数。
- 图中部分数据看不清时，先列出无法确认的项目。不要补数字，也不要据此批评数据不准确。
- 不知道是 Academic 还是 GT 时，先根据内容推断；若两种解释都会改变评分，再向用户确认。

## 二、评分原则

- 逐项给估计区间，例如 `6.0–6.5`，并说明支持下限和上限的文本证据。
- 只有在证据充分时才给单一分数。最终成绩仍以 IELTS 考官为准。
- Task Achievement 的判断必须结合原题或图表。
- 不因没有采用四段式、没有以 `Overall` 开头、没有写固定数量的数据而自动扣分。
- 不按错误总数直接换算 GRA。区分偶发错误、系统性错误和影响理解的错误。
- 引用用户原句作为证据。不要只复述评分描述符。
- 优先做最小必要修改。除非用户要求，不要用一篇全新范文替代其作文。

## 三、四项检查

### Task Achievement

Academic：

- 是否准确说明图表对象、地点、单位和时间范围。
- 是否有清晰 overview，概括主要趋势、差异、阶段或地图变化。
- 是否选择并突出关键特征，而不是逐项罗列。
- 主体段的数据是否准确，并足以支持主要特征。
- 是否加入图表没有提供的原因、观点或推测。

General Training：

- 写信目的是否清楚。
- 三个 bullet points 是否全部覆盖并适当展开。
- 语气是否符合收信人、关系和写信目的。
- 请求、解释、投诉、邀请等交际目标是否真正完成。

### Coherence & Cohesion

- 信息分组是否有逻辑，段落是否帮助读者理解。
- 比较对象、时间顺序或流程顺序是否容易跟随。
- 连接词是否准确，指代是否清楚，关键词重复是否必要。
- 是否存在机械连接、跳跃、含糊回指或一句塞入太多信息。

### Lexical Resource

- 图表、比较、趋势、流程或书信语言是否准确。
- 搭配、词形和语域是否合适。
- 重复是否真的限制表达，而不是正常复现关键词。
- 不把普通词或单个表达自动视为低分证据。

### Grammatical Range & Accuracy

- 结构是否有一定范围，而且复杂结构仍然受控。
- 检查冠词、数与一致、动词、从句、句子边界、词序、介词、指代、标点、拼写和词形。
- 判断错误是否重复出现，是否妨碍理解。
- Academic Task 1 重点检查时间与数据对应的时态、比较结构和流程被动语态；GT 还要检查礼貌表达和句子完整性。

## 四、默认输出

用户没有指定格式时，使用下面的标准版。用户只问一个局部问题时，直接回答该问题，不必强行输出完整报告。

### 1. 总体判断

- 估计总分区间
- 当前最强项
- 当前最限制分数的一项
- 输入限制，例如缺少图表或部分文字无法辨认

### 2. 四项评分表

| 项目 | 估计区间 | 原文证据 | 距离下一档还缺什么 |
|---|---|---|---|
| Task Achievement |  |  |  |
| Coherence & Cohesion |  |  |  |
| Lexical Resource |  |  |  |
| Grammatical Range & Accuracy |  |  |  |

每项至少引用一处具体文本。没有足够信息时写“暂不评分”，并说明原因。

### 3. 错误记录

| 原句片段 | 代码 | 问题 | 最小修改 | 是否系统性 |
|---|---|---|---|---|

建议使用稳定代码，方便学生长期记录：

- `TA-OV` overview；`TA-SEL` 特征筛选；`TA-DATA` 数据准确性；`TA-TONE` GT 语气与目的。
- `CC-ORG` 组织；`CC-LINK` 衔接；`CC-REF` 指代。
- `LR-COLL` 搭配；`LR-WF` 词形；`LR-REG` 语域；`LR-PREC` 精确性。
- `GRA-ART` 冠词；`GRA-AGR` 数与一致；`GRA-V` 动词；`GRA-SENT` 从句或句子边界；`GRA-WO` 词序；`GRA-PUNC` 标点。

错误较少时全部列出。错误很多时，完整统计重复类型，只展示最有代表性的 10–15 处，并明确说明哪些错误被合并。

### 4. 优先修正

给出不超过三项，按“下一篇最可能提高表现”的顺序排列。每项必须包含：

- 观察到的问题；
- 为什么它限制分数；
- 下一篇可以执行的检查动作。

### 5. 示范修改

默认只改最需要处理的一段或几句。保留学生原意，使用学生可以模仿的语言，并简要指出改动理由。用户明确要求时才提供完整重写。

### 6. 微练习

根据本篇最高频问题生成三道短练习。练习应要求学生自己改写、选择或补全，不立即替学生完成；用户作答后再反馈。

## 五、反馈语气

- 先说判断，再给证据。
- 区分错误、较弱选择和个人风格偏好。
- 不使用“这句很高级”“考官会喜欢”等无法验证的评价。
- 不承诺“改完这三点就能提高 0.5 分”。
- 中文讲解可以直白，英文修改必须自然并保留原意。
