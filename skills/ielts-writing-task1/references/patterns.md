# IELTS Task 1 句式 Cheat Sheet（填空模板版）
### Academic 图表（线图 / 柱图 / 饼图 / 表格 / 混合图 / 流程 / 地图）+ GT 书信

> **这个文件只讲 Task 1 句式。** Task 2 句式在 `../task2/patterns.md`。
>
> **格式说明（每个句式都是三层结构）**
> ```
> ① 骨架（背死这一行，不许改）
>    There was a {程度形容词} {上升名词} in {被测物} {介词短语}.
> ② 同义替换槽（换词不换结构）
>    上升名词: increase / rise / growth / upsurge ｜ 程度形容词: significant / slight / steady
> ③ Points 槽（换内容不换结构，任何图形通用）
>    被测物 = the number of {人} who {动词} ｜ the proportion of {人} ｜ spending on {事物}
> ```
> **符号**：`{ }` = 你要填的内容点；`A / B / C` = 可互相替换的固定块；🅐 = 6.5 保底 ｜ 🅑 = 7.5 主力 ｜ 🅒 = 8+ 加分。
> **铁律**：骨架必须一字不差背熟，替换只在槽内进行。

## T1-0 四段式总骨架

```
段落 1  Introduction  1 句   —— 改写题目
段落 2  Overview      2 句   —— 总体趋势 + 最高级/比较（不放数字）
段落 3  Body 1        3–4 句 —— 第一组特征 + 数据 + 比较
段落 4  Body 2        3–4 句 —— 第二组特征 + 数据 + 比较
```

**每段内部的句子功能（照这个顺序写，不会乱）**

```
Body 段 = ① 主题句（这段讲什么）
        + ② 数据支撑（带具体数字）
        + ③ 比较（与另一项/另一年对比）
        + ④（可选）转折或补充（while / whereas / by contrast）
```

**Points 槽（跨图形通用）**
```
"被测物"的四种写法（任选，避免重复）：
  the number of {人/物} who {动词}        the proportion / percentage of {人/物}
  the figure for {项目}                   {项目} + 名词化（car production / visitor numbers）
```

## T1-1 Introduction 改写骨架

### 骨架 1 🅐 —— 最稳的一句

```
The {图表名词} {动词} {信息内容} in {地点} {时间范围}.
```
```
图表名词: chart / graph / line graph / bar chart / pie chart / table / diagram / figure
动词:     shows / illustrates / depicts / indicates / reveals / compares / gives information about / provides data on / outlines
信息内容: the {变化名词} in {被测物} ｜ the proportion of {人} who {动词} ｜ the amount of {事物} {动词-ed}
时间范围: between {年} and {年} / over a {数字}-year period / from {年} to {年}
```

**示例（填好的样子）**
- The **line graph illustrates** the **changes in** electricity **consumption** in **four countries over a 20-year period**.
- The **bar chart compares** the **proportion of** households **who recycled waste** in **three cities between 2005 and 2015**.

### 骨架 2 🅑 —— 名词化 + 更紧凑

```
The {图表名词} {动词} {信息内容-名词化} {地点} {时间范围}.
```
```
名词化替换表（左 = 题目原词，右 = 改写词）：
  the number of people who visited  → visitor numbers / the number of visitors
  spending on X                      → expenditure on X
  the production of coffee           → coffee production
  the amount of money made           → revenue / income / turnover
  the level of unemployment          → the unemployment rate
  the quality of food in supermarkets → supermarket food quality
  investment in research             → research investment
  the number of theme park visitors  → theme park visitor numbers
```

### 骨架 3 🅑 —— 以"变化"为主语（适合含时间跨度的图）

```
The {图表名词} {动词} how {被测物} {变化动词} over the period from {年} to {年}.
```
```
变化动词: changed / developed / evolved / fluctuated
```

### 骨架 4 🅒 —— 双图题专用

```
The {图表名词 1} {动词} {信息内容 1}, while the {图表名词 2} {动词} {信息内容 2}.
```
```
动词 1: shows / illustrates        动词 2: gives information about / provides data on
```

### ⚠️ Introduction 禁忌
- ✗ 照抄题目原句（必须换名词或换动词，至少改两处）
- ✗ 写原因、写观点、写"我"
- ✗ 超过 2 句（这是最不值钱的段落）

## T1-2 Overview 概述骨架

> Overview 决定 Task Achievement 上限：**没有它就 ≤5.0**；有趋势 + 比较才 7.0+。**不放具体数字**。

### 骨架 1 🅐 —— 通用最高级型（任何图形都能用）

```
Overall, {最高项} was consistently the most {形容词}, whereas {最低项} remained the least {形容词} throughout the period.
```
```
形容词: popular / common / significant / widely used / pronounced / notable
替换 Overall: It is clear that / It is noticeable that / In general / Broadly speaking
```

### 骨架 2 🅐 —— 总体趋势型（有时间轴）

```
It is clear that {被测物} {趋势动词} overall, with {补充特征}.
```
```
趋势动词: rose / fell / increased steadily / showed an upward trend / declined gradually
补充特征: the figure for {X} overtaking that of {Y} / the most dramatic change occurring in {Y}
```

### 骨架 3 🅑 —— 让步式概述（有反向细节时）

```
It is noticeable that, although {反向细节}, the overall trend was towards {总方向}.
```

### 骨架 4 🅑 —— 无时间轴（单年数据）专用

```
Overall, {项目 A} accounted for the largest share of {总量}, while {项目 B} was the least {形容词}.
```
```
⚠️ 单年数据不能写 increase / decrease / fluctuated —— 只能比较
```

### 骨架 5 🅑 —— 两条线/两组数据型

```
Overall, {组 A} {趋势}, whereas {组 B} {相反趋势}, with {X} being the only category that {例外}.
```

### 骨架 6 🅒 —— 程度 + 差距型

```
It is clear that the gap between {X} and {Y} {动词} over the period, and that {X} remained {形容词} throughout.
```
```
动词: widened / narrowed / remained stable / fluctuated

### 按图形选 Overview 内容（Points 槽）

| 图形 | Overview 必须包含 |
|---|---|
| 线图 | 总体走向 + 始终最高/最低的那条线（**不写单个峰值**）|
| 柱图 | 最高组 vs 最低组 + 组间差距 |
| 饼图 | 最大份额 + 最小份额（+ 两年的话写哪块变大/变小）|
| 表格 | 整体最高/最低的行列 + 最显著的差异 |
| 混合图（两图）| **每个图各一句**，或找两条共同特征 |
| 流程图 | **总阶段数** + 起点 + 终点 |
| 地图 | **最大变化** + 变化数量/性质 |
```

## T1-3 趋势上升骨架

### 骨架 1 🅐 —— 名词路径（there be 型）

```
There was a {程度形容词} {上升名词} in {被测物} {介词短语}.
```
```
上升名词: increase / rise / growth / upsurge / upturn / climb
程度形容词: significant / substantial / marked / considerable / dramatic / sharp / steady / gradual / moderate / slight / marginal
介词短语: from {起点} to {终点} ｜ of {幅度} ｜ between {年} and {年} ｜ over the period
```

### 骨架 2 🅐 —— 动词路径（最常用）

```
{被测物} {上升动词} {程度副词} {介词短语}.
```
```
上升动词: rose / increased / grew / climbed / went up / jumped / surged / soared / rocketed
程度副词: significantly / substantially / markedly / considerably / dramatically / sharply / steadily / gradually / moderately / slightly / marginally
```
> ⚠️ `rocket / soar / surge` 本身已含"大幅"，**后面不再加程度副词**。

### 骨架 3 🅑 —— 时间作主语（句式变化加分）

```
{年份 / 时期} saw / witnessed a {程度形容词} {上升名词} in {被测物}.
```
```
示例：2010 saw a sharp rise in the number of electric cars sold.
	    The five-year period witnessed a steady increase in online sales.
```

### 骨架 4 🅑 —— 经历型（避免主谓重复）

```
{被测物} experienced / underwent a {程度形容词} {上升名词} {介词短语}.
```

### 骨架 5 🅑 —— 分词收尾（把两句压成一句）

```
{被测物} {上升动词} {程度副词} {介词短语}, {分词} to {数据} in {年}.
```
```
分词: rising / reaching / climbing / peaking / before rising / after which it rose
```

### 骨架 6 🅒 —— 幅度 + 终点一起写

```
{被测物} {上升动词} by {幅度} to {终点数据} in {年}, {分词短语}.
```
```
示例：Coffee exports rose by 25% to 12,000 tonnes in 2015, reaching their highest level of the period.
```

## T1-4 趋势下降骨架

> 结构与上升完全相同，只换词表。

```
骨架 1  There was a {程度形容词} {下降名词} in {被测物} {介词短语}.
骨架 2  {被测物} {下降动词} {程度副词} {介词短语}.
骨架 3  {年份} saw a {程度形容词} {下降名词} in {被测物}.
骨架 4  {被测物} experienced a {程度形容词} {下降名词} {介词短语}.
骨架 5  {被测物} {下降动词} {程度副词}, {分词} to {数据} in {年}.
```
```
下降名词: decrease / decline / fall / drop / downturn / reduction
下降动词: fell / declined / decreased / dropped / went down / dipped / plummeted / plunged
程度副词: significantly / substantially / markedly / sharply / steadily / gradually / moderately / slightly
```
> ⚠️ `plummet / plunge` 不加程度副词。单位不可数时用 `a 20% fall in` 而非 `a fall of 20%` 亦可，但 `a fall of 20% in X` 更标准。

**高分细节**：`by` = 幅度，`to` = 终点。
```
fell by 25%      下降了 25%
fell to 20%      降到了 20%
fell from 45% in 1998 to 20% in 2010
```

## T1-5 持平 / 波动 / 峰谷骨架

### 持平

```
骨架 1  {被测物} levelled off at {数据} {时间}.
骨架 2  {被测物} remained {形容词} at {数据} {时间}.
骨架 3  There was little change in {被测物}, which stood at {数据} {时间}.
骨架 4  {被测物} plateaued at {数据} {时间}.
```
```
形容词: stable / steady / constant / unchanged / flat / static
替换 levelled off: flattened out / stabilised / stopped rising
```

### 波动

```
骨架 1  {被测物} fluctuated {程度副词} {时间范围}.
骨架 2  There were {形容词} fluctuations in {被测物} {时间范围}.
骨架 3  {被测物} fluctuated between {低值} and {高值} {时间范围}.
骨架 4  {被测物} varied around {数据} {时间范围}.
```
```
程度副词: slightly / moderately / considerably / wildly（慎用）
形容词:   slight / moderate / marked / sharp
```

### 峰值 / 谷值

```
骨架 1  {被测物} peaked at {数据} in {年}.
骨架 2  {被测物} reached a peak / a high of {数据} in {年}.
骨架 3  {被测物} hit a low / reached its lowest point of {数据} in {年}.
骨架 4  {被测物} bottomed out at {数据} in {年}, after which it {恢复动词}.
骨架 5  {被测物} reached its highest / lowest level {时间范围}, at {数据}.
```
```
恢复动词: recovered / rose again / began to climb / rebounded
```

## T1-6 起点终点 / 静态定位骨架

```
骨架 1  {被测物} stood at {数据} in {年}.                          （静态：单点数据）
骨架 2  {被测物} started / began at {数据} in {年}.                 （起点）
骨架 3  {被测物} ended / finished at {数据} in {年}.                （终点）
骨架 4  In {年}, {被测物} stood at {数据} before {分词短语}.         （起点 + 后续）
骨架 5  As the {图表} shows, in {月}, the figure stood at {数据} before declining steadily to a low of {数据}.
骨架 6  {被测物} accounted for {数据} of {总量} in {年}.             （占比型定位）
```
**替换 stood at**：was / reached / recorded / totalled / amounted to
**Points 槽**：`the figure for {项目}` 是万能主语 —— 想不起怎么措辞时就用它。

## T1-7 比较与倍数骨架

### 最高级 / 比较级

```
骨架 1  {A} was the most {形容词} {类别名词} {范围}.
骨架 2  {A} was more {形容词} than any other {类别名词}.
骨架 3  {A} was more {形容词} than {B}.
骨架 4  {A} was more {形容词} among {群体 1} than {群体 2}.
骨架 5  More {群体 1} than {群体 2} chose {A}.
```
```
形容词: popular / common / widely used / favoured / significant / pronounced
```

### 倍数与比例

```
骨架 1  {A} was twice / three times as {形容词} as {B}.
骨架 2  {A} was three times the figure for {B}.
骨架 3  The figure for {A} was {数字} times higher than that for {B}.
骨架 4  A higher percentage of {群体 1} than {群体 2} {动词}.
骨架 5  {A} accounted for roughly half / a third / a quarter of {总量}.
```

### 相似与对比

```
骨架 1  The figure for {A} was almost identical to that for {B}.
骨架 2  {A} and {B} were broadly similar, at {数据} and {数据} respectively.
骨架 3  Compared with / to {B}, {A} was considerably higher.
骨架 4  {A} was considerably higher compared with {B}.
骨架 5  In contrast to {A}, {B} {动词短语}.
骨架 6  {A} {动词}, whereas {B} {动词}.                             （whereas 后接完整从句）
骨架 7  While {A} {动词}, {B} {动词}.
骨架 8  {A} {动词}, while {B} {动词}.
```
```
respectively  分别（前文按顺序给出两项数据时用）
in turn       依次、相应地
the former / the latter   前者 / 后者（只在两项时用，需指代清楚）
```

### 关于 compared with / whereas / although 的选择

| 连接词 | 后面接什么 | 例 |
|---|---|---|
| `whereas` / `while` | **完整从句**（主+谓）| X rose, **whereas** Y fell. |
| `compared with / to` | **名词短语** | **Compared with** Y, X was higher. |
| `despite / in spite of` | **名词短语** | **Despite** the rise in X, Y fell. |
| `although / though` | **完整从句** | **Although** X rose, Y fell. |

## T1-8 份额 / 占比骨架

```
骨架 1  {项目} accounted for {数字}% of {总量}, making it the largest / smallest {类别名词}.
骨架 2  The proportion of {项目} stood at {数字}%, compared with just {数字}% for {项目 2}.
骨架 3  {项目} made up / constituted / represented {数字}% of {总量}.
骨架 4  {项目} took up the largest share, at {数字}%.
骨架 5  Between {年} and {年}, the share of {项目} {上升/下降动词} from {数字}% to {数字}%.
骨架 6  The percentage of {群体} who {动词} {上升/下降动词} {程度副词}.
```
```
占比动词替换: account for / make up / constitute / represent / comprise / take up / form
⚠️ comprise 后面不加 of：X comprises 30% of the total. ✓  ｜ X comprises of 30% ✗
⚠️ 份额 + 变化时注意："the share of X" 是主语，动词用单数。
```

**份额的模糊表达（当数字过于密集时）**
```
just under / just over / around / approximately / roughly / almost / nearly / slightly more than
more than half / fewer than one in five / a mere {数字}% / as much as {数字}%
```

## T1-9 程度副词与形容词搭配表

**核心规则**：`动词 → 配副词`；`名词 → 配形容词`。两句意思相同，句式不同。

| 幅度 | 形容词（+ 名词）| 副词（+ 动词）|
|---|---|---|
| 剧烈 | dramatic, sharp, steep, substantial, significant, considerable, marked | dramatically, sharply, steeply, substantially, significantly, considerably, markedly |
| 中等 | moderate, noticeable | moderately, noticeably |
| 平缓 | gradual, steady, consistent | gradually, steadily, consistently |
| 微小 | slight, marginal, minimal | slightly, marginally, minimally |
| 快速 | rapid, quick, swift | rapidly, quickly, swiftly |
| 缓慢 | slow | slowly |

```
对照练习（同一个意思的两种写法）：
  There was a significant increase in the number of X.   =  The number of X increased significantly.
  There was a slight fall in CD sales in 2010.           =  CD sales fell slightly in 2010.
                                                           2010 saw a slight fall in CD sales.
                                                           CD sales experienced a slight fall in 2010.
```
**⚠️ 三大搭配炸弹**
1. `plummet / plunge / rocket / soar / surge` **不能**再加程度副词。
2. 名词后必须加 `in`：an increase **in** prices ✓ ｜ an increase of prices ✗
3. 幅度用 `of`，终点用 `to`：a rise **of** 10% ；rose **to** 200。

## T1-10 时间表达与数字介词

```
时间范围
  from {年} to {年}              between {年} and {年}
  over the period from {年} to {年}   during / throughout the period from {年} to {年}
  over a {数字}-year period        over the next {数字} years
  during the first / last two years   for the following five years
  in the first / last three months of the year   for the rest of the year
  at the beginning of the period   at the end of the period
  over a ten-year period          in 1990

顺序
  after that / then / subsequently / following this / thereafter
  until / up to / by

介词与数字
  in 2000            （在某年）
  by 1995            （到某年为止）
  fell to 20%        （降到）
  fell by 25%        （降了）
  from 45% in 1998 to 20% in 2010
  an increase of 10% in the number of …
  at 15%             （处于某数值）
  around / about / approximately / roughly 15%
  just over / just under / nearly / almost / more than / less than 15%
```

**时态决策**

| 图形 | 时态 |
|---|---|
| 全部年份在过去 | 一般过去时 |
| 现在 / 无时间 | 一般现在时 |
| 含未来年份 | is expected / predicted / projected / likely to + V；或 will have + p.p. |
| 流程图 | 一般现在时被动 |

## T1-12 流程图骨架

> 三原则：**一般现在时被动** + **写出总阶段数与起终点**（overview）+ **变换顺序连接词**。

### Overview 骨架

```
Overall, the process consists of {数字} main stages, beginning with {起点} and culminating in {终点}.
```
```
替换 culminating in: ending with / finishing with / resulting in / and the final product is {成品}
若有循环: Overall, the process comprises {数字} stages, after which the cycle begins again.
```

### 阶段骨架

```
骨架 1  First, {原料} is {过去分词} and {过去分词}.
骨架 2  Next / After that / Subsequently, the {中间产物} is {过去分词} before being {过去分词}.
骨架 3  Once {原料} has been {过去分词}, it is {过去分词} and transported to {地点}.
骨架 4  At the following / final stage, {产物} is {过去分词} and {过去分词}.
骨架 5  {地点} is where {原料} is {过去分词}.
骨架 6  The resulting {产物} is then {过去分词} into {成品}.
骨架 7  Finally, {成品} is {过去分词} and the cycle is repeated.
```
```
顺序连接词库（变换使用，别只用 first/then）：
  To begin with / At the first stage / Initially / First of all
  Next / Then / After this / Following this / Subsequently / At this point
  Once … / After … / Before … / Meanwhile
  At the final stage / Finally / Lastly / Eventually
```
```
常用过去分词: collected / transported / delivered / heated / cooled / melted / crushed / mixed / filtered / separated / dried / packaged / labelled / distributed / sold / stored / processed / converted into / removed / added
```

**⚠️ 流程图禁忌**
- ✗ 加原因、加评价（"this is a good method"）
- ✗ 全部用主动语态（"people heat the water"）
- ✗ 写错阶段数

## T1-13 地图骨架

> 三件事：**方位语言** + **变化动词** + **被动语态**。

### Overview 骨架

```
骨架 1  Overall, the most striking change is that {最大变化}, while {次要变化}.
骨架 2  Over the period, {地点} was transformed from {旧描述} into {新描述}.
骨架 3  The {X} was the only feature that remained unchanged.
骨架 4  Overall, the {地点} became considerably more {形容词} than before.
```
```
形容词: built-up / developed / commercial / residential / accessible / green / industrial
```

### 方位语言（Points 槽）

```
to the north / south / east / west of {参照物}
in the north / south-east of {地点}
in the centre of {地点}          on the coast / on the coast of {地点}
on the corner of {街} and {街}   alongside {河/路}
adjacent to / next to / close to / near    opposite / across from
surrounded by {事物}             in the northern part of {地点}
at the southern end of {地点}    to the left / right of {参照物}
```

### 变化骨架

```
骨架 1  {旧事物} was {过去分词} and replaced by {新事物}.
骨架 2  A new {新事物} was built / constructed / erected on the site of the old {旧事物}.
骨架 3  The {区域}, which had previously been {旧状态}, was converted into {新状态}.
骨架 4  The {事物} was extended / expanded to include {新增部分}.
骨架 5  The {事物} in the {方位} was demolished / pulled down / knocked down to make way for {新事物}.
骨架 6  The {道路} was widened / pedestrianised, allowing {效果}.
骨架 7  A {事物} was added to the {方位} of the site.
骨架 8  {事物} was relocated to the {方位}.
骨架 9  The {区域} was planted with {植物} / turned into {用途}.
骨架 10 The {事物} was removed to create space for {新事物}.
```
```
变化动词库: built / constructed / erected / established / added / extended / expanded /
            converted into / transformed into / replaced / demolished / pulled down /
            knocked down / removed / relocated / pedestrianised / widened / planted with /
            modernised / renovated / upgraded / developed into
```

**地图三段写法示例（结构参考）**
```
Introduction: The two maps illustrate the changes that took place in {地点} between {年} and {年}.
Overview:     Overall, the most striking change is that {农田 → 住宅区}, while {铁路保持原状}.
Body 1:       In the north of the map, {旧事物} was demolished to make way for {新事物}. The {区域} to the south...
Body 2:       The {区域} in the east, previously {旧用途}, was extended and converted into {新用途}. A new {事物} was also added...
```

## T1-14b 横向 / 纵向比较骨架（表格题专用）

> 表格题没有"形状"，只能靠自己找规律。三种比较方向：**横向（行内不同列）**、**纵向（同列不同行）**、**极值**。

### 骨架 1 —— 最高/最低行
```
With regard to {行/维度}, {A} had the highest figure, at {数据}, whereas {B} recorded the lowest, at {数据}.
```
### 骨架 2 —— 倍数与差距
```
{项目} in {A} was {数据}, roughly {倍数} that of {B}.
The gap between {A} and {B} was particularly pronounced in terms of {维度}.
```
### 骨架 3 —— 显著对比
```
There was a striking contrast between {A} and {B} in terms of {维度} ({数据} vs {数据}).
```
### 骨架 4 —— 排序与紧随
```
{A} ranked first in {维度}, followed by {B} at {数据} and {C} at {数据}.
```
### 骨架 5 —— 相似性
```
{A} and {B} recorded broadly similar figures for {维度}, at {数据} and {数据} respectively.
```
### 骨架 6 —— 异常 / 例外
```
The most notable exception was {项目}, which {异常表现}.
{A} was the only {类别} in which {相反表现}.
```
```
Points 槽（表格常见维度）：{国家} / {年龄段} / {性别} / {年份} / {支出类别} / {产业部门}
⚠️ 表格题必须自己选 2–3 个维度来写，不要逐行翻译；overview 要写"哪个行列整体最高/最低"。
```

## T1-14c GT 书信骨架（General Training Task 1）

> 语域（formal / semi-formal / informal）由**收信人关系**决定，不是一律正式。称呼一旦选定，全篇不能漂移。

### 通用四段骨架
```
第 1 段  称呼 + 目的句 + 背景一句
第 2 段  覆盖 bullet 1（+ 细节/理由）
第 3 段  覆盖 bullet 2（+ bullet 3）
第 4 段  收尾动作 + 客套结束句 + 落款
```

### 目的句骨架（第一句）
```
骨架 1  I am writing to {动词} {事物}.
          动词: enquire about / complain about / apply for / request / apologise for / invite you to / thank you for / suggest
骨架 2  I am writing with regard to {事物}.
骨架 3  I am writing in response to {来源 / your advertisement}.
骨架 4  I am writing to express my dissatisfaction with {事物}.
骨架 5  I am writing to let you know that {情况}.        （informal 也可用）
```

### 各功能骨架

**投诉**
```
骨架 1  Unfortunately, {问题} did not match the description in your advertisement.
骨架 2  To make matters worse, {进一步问题}.
骨架 3  I would therefore be grateful if you could {要求}.
骨架 4  I would appreciate it if you could {要求} at your earliest convenience.
骨架 5  I look forward to hearing how you intend to resolve this matter.
```
**道歉**
```
骨架 1  I am extremely sorry that {事件}.
骨架 2  The reason for this was that {原因}.
骨架 3  To make up for the inconvenience, I would like to {补偿}.
骨架 4  I hope you can accept my apologies, and I would be happy to {补救}.
```
**询问 / 请求**
```
骨架 1  Could you please let me know whether {信息}?
骨架 2  I would be grateful if you could provide me with {信息}.
骨架 3  I would also like to know if {条件}.
骨架 4  I would appreciate any advice you can offer on {问题}.
```
**建议**
```
骨架 1  I would like to suggest that {建议}.
骨架 2  It might be a good idea to {建议}.
骨架 3  One possible solution would be to {方案}.
骨架 4  You might find it helpful to {做法}.
```
**邀请（非正式）**
```
骨架 1  I was wondering if you would like to {活动}.
骨架 2  It would be great if you could {动作}.
骨架 3  Do let me know if {条件} — it would be lovely to see you.
```
**感谢**
```
骨架 1  I am writing to thank you for {帮助}.
骨架 2  I really appreciate {事物} — it made a great difference to {对象}.
```

### 结束句与落款
```
I look forward to hearing from you.                          （formal / semi-formal）
I look forward to your reply.                                （formal）
Thank you for your time and consideration.                   （申请信）
Please do not hesitate to contact me if you need further information.
Drop me a line when you get a chance.                        （informal）
Best wishes / Take care / Lots of love                       （informal 落款）
Yours sincerely / Yours faithfully / Kind regards            （formal 落款）
```
**铁律**：① 三个 bullet points 必须逐条覆盖，每条都要有细节；② 语域全篇一致；③ 语气礼貌且**体谅对方**；④ 150–180 词即可。

## T1-15 Task 1 通用 Points 银行

> Task 1 不需要"观点"，只需**特征**。以下是任何图形都可能用到的特征类型，照单勾选即可。

| 特征类型 | 句式触发词 | 说明 |
|---|---|---|
| 总体方向 | Overall, … rose/fell | overview 必备 |
| 最高项 | the highest / the most popular | overview + body |
| 最低项 | the lowest / the least | body |
| 最大变化 | the most dramatic change was in … | overview |
| 无变化项 | remained stable / was the only feature that did not change | overview 或 body 末 |
| 交叉点 | overtook / surpassed / exceeded | 线图 body |
| 差距扩大/缩小 | the gap between X and Y widened / narrowed | 线图 body |
| 反转 | X rose initially but then fell / X fell before recovering | body |
| 例外 | with the exception of X / X was the only category that … | body |
| 相似 | X and Y followed a similar pattern | body |
| 相反 | X and Y moved in opposite directions | body |

**数据选择规则**
```
全文只写 6–7 个数字。优先级：
  ① 起点的数值       ② 终点的数值       ③ 最高值 / 峰值
  ④ 最低值 / 谷值     ⑤ 交叉或反转处的数值 ⑥（两图时）关键对照值
忽略：中间每一年的小波动、与趋势不符的个别年份（留给 body 一句带过即可）
```
