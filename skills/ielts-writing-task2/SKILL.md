# IELTS Writing Task 2（议论文，A 类与 G 类通用）

任务 2 占写作总分 2/3，建议用时 40 分钟，官方字数下限为 250 词。议论文五类题型共用一套骨架系统 + 论点生成引擎。

## 核心原则（先读，别跳过）

1. **先拆题，再动笔**：先确认「话题 + 指令词 + 我的回答 + 主要理由」。遗漏指令会限制 Task Response。
2. **立场清楚且一致**：需要表达观点时，让读者容易找到并跟随立场。`I believe / in my opinion` 可以使用，但不是唯一写法。
3. **把理由展开清楚**：连续追问 why / so what，直到读者能看出理由怎样导向结论。"理由 → 机制解释 → 例证或说明 → 后果"是训练框架，不要求每段机械凑齐四步。
4. **四段式是安全默认值**：两主体段通常便于控制时间和立场，但段落数、段长和论证顺序应服从题目。
5. **用词准，不是用词难**：配得准的常见词通常比孤立生僻词可靠。是否使用少见词取决于准确性、语域和语境，不设数量配额。
6. **衔接自然**：连接词没有官方次数上限。避免机械重复，并综合使用逻辑推进、指代、替换和关键词复现。
7. **不编数据**：用具体案例 + 机制推理代替虚构百分比。

## 五类题型 → 骨架速查

| 指令 | 立场 | 结构 |
|---|---|---|
| To what extent do you agree or disagree? | 明确表态（可部分同意） | 引言立场 → 理由1 → 理由2+让步反驳 → 结论 |
| Discuss both views and give your own opinion. | 两边都讨论 + 明确站边 | View A → View B + 我的判断 → 结论 |
| Do the advantages outweigh the disadvantages? | 倾向一边 + 承认另一边 | 优势面 → 劣势面（承认+指出局限）→ 重申"更重" |
| Causes / Problems + Solutions | 不选边 | 原因（因果链）→ 方案（与原因一一对应，写清执行者）|
| 双问句（两个问号） | 分别回答 | 先扫题干圈出两问，各占一个主体段，篇幅均衡 |

## 工作流

1. **判定题型**（上表）→ 2. **按模式工作**：

| 模式 | 做什么 |
|---|---|
| **Teach** | 讲该题型的段落骨架与论点打法，引用 guide.md 对应章节 |
| **Outline** | 拆题：话题 / 指令 / 立场 / 两条理由 + 各自的逻辑链三层 |
| **Model** | 写高分方向范文：patterns.md 骨架 + vocabulary.md 话题搭配，写完自检 |
| **Grade** | 先读 `references/grading-protocol.md`，检查输入是否足以评分，再输出四项区间、文本证据、错误记录、优先修正和微练习 |
| **Drill** | 从 prompt-bank.md 抽题做 30 秒拆题训练，或出题限时写作 |

## 论点生成引擎（用户说"想不出观点"时）

按顺序用三把铲子挖论点：
1. **利益相关者**：government / employers / schools / individuals / communities——逐个问"这对他们有什么影响"；
2. **维度切换**：经济 / 健康 / 环境 / 时间 / 公平 / 心理 / 长期 vs 短期；
3. **逻辑链追问**：对每条理由连续问 2–3 层"why / so what"，推到可感知的后果。

## 评分协议（Grade 模式）

- **Task Response**：是否回答了全部问题？立场是否清晰、充分发展且前后一致？论点是否相关并得到解释或支持？是否达到 250 词？
- **Coherence & Cohesion**：信息是否容易跟随？论点顺序和段落是否合理？连接、指代和替换是否清楚自然？不要因没有采用四段式而自动扣分。
- **Lexical Resource**：词汇是否准确、自然并适合语域？重复是否影响表达？不要把 `Nowadays`、`Some people believe` 或普通词本身当成自动扣分项，判断它们在具体语境中是否空泛、机械或不准确。
- **Grammatical Range & Accuracy**：结构是否有范围、灵活性和控制力？逐句记录语法与标点问题、是否系统性重复、是否影响理解。无错句比例只能辅助诊断，不能直接换算 Band。

评分时优先给出区间，例如 `6.5–7.0`，并分别指出支持区间下限和上限的证据。官方没有规定 265–330 词、固定四段或特定连接词次数；这些只能作为时间管理建议。
