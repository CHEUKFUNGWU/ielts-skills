# IELTS Writing Task 2（议论文，A 类与 G 类通用）

任务 2 占写作总分 2/3，官方时限 40 分钟，字数下限 250 词（建议 265–330）。议论文五类题型共用一套骨架系统 + 论点生成引擎。

## 核心原则（先读，别跳过）

1. **先拆题，再动笔**：30 秒说出「话题 + 指令词 + 我的立场 + 两条理由」。指令词没被满足 = Task Response 直接掉档。
2. **立场必须一致**：引言与结论都明确表态，主体段保持克制；`I believe / in my opinion` 在观点题里本来就该用。
3. **机制层是 6.5 与 7.5 的分水岭**：每个理由连续追问 why 到第二、三层后果——"理由 → 机制解释 → 例证 → 后果"，不是"理由 + 例子"两层完事。
4. **结构固定**：四段式（两主体段）最稳。引言 ≈50 词，主体 ≥170 词，结论 30–40 词。
5. **用词准，不是用词难**：配得准的常见词 > 孤立的生僻词。每篇最多 1–2 个"炫技词"，且必须是你见过真实搭配的。
6. **衔接自然**：`Moreover / Furthermore / In addition` 全篇 ≤1 次；多用指代打包（`this trend / such measures`）与让步转折。
7. **不编数据**：用具体案例 + 机制推理代替虚构百分比。

## 五类题型 → 骨架速查

| 指令 | 立场 | 结构 |
|---|---|---|
| To what extent do you agree or disagree? | 明确表态（可部分同意） | 引言立场 → 理由1 → 理由2+让步反驳 → 结论 |
| Discuss both views and give your own opinion. | 两边都讨论 + 明确站边 | View A → View B + 我的判断 → 结论 |
| Do the advantages outweigh the disadvantages? | 倾向一边 + 承认另一边 | 优势面 → 劣势面（承认+指出局限）→ 重申"更重" |
| Causes / Problems + Solutions | 不选边 | 原因（因果链）→ 方案（与原因一一对应，写清执行者）|
| 双问句（两个问号） | 分别回答 | 先扫题干圈出两问，各占一个主体段，篇幅均衡 |

## 工作流

1. **判定题型**（上表）→ 2. **按模式工作**：

| 模式 | 做什么 |

## 论点生成引擎（用户说"想不出观点"时）

按顺序用三把铲子挖论点：
1. **利益相关者**：government / employers / schools / individuals / communities——逐个问"这对他们有什么影响"；
2. **维度切换**：经济 / 健康 / 环境 / 时间 / 公平 / 心理 / 长期 vs 短期；
3. **逻辑链追问**：对每条理由连续问 2–3 层"why / so what"，推到可感知的后果。

## 评分协议（Grade 模式）

- **Task Response**：是否回答了**全部**问题？立场是否一致？每段是否展开到"机制 + 例证 + 后果"？字数 265–330？
- **Coherence & Cohesion**：四段是否清晰？主题句是否撑起全文？衔接是否自然？
- **Lexical Resource**：话题搭配是否准确？有无重复用词？是否踩雷区（`Nowadays` 句首、`Some people believe` 句首、`last but not least`、`kids`、`thing`）？
- **Grammatical Range & Accuracy**：复杂结构是否可控？逐句数错误并归五类（冠词 / 单复数 / 时态 / 介词搭配 / 拼写词形）。band 8 ≈ 14 句里 12–13 句无错。
