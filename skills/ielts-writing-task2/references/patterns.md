# IELTS Task 2 句式 Cheat Sheet（填空模板版）
### 议论文（A 类与 G 类通用）｜ 按 16 组写作功能组织

> **这个文件只讲 Task 2 句式。** Task 1 句式在 `../task1/patterns.md`。
>
> **格式说明（每个句式都是三层结构）**
> ```
> ① 骨架（背死这一行，不许改）
>    {执行者} could {措施}, which would {效果}.
> ② 同义替换槽（换词不换结构）
>    执行者: governments / local authorities / schools / employers / the media
>    could → should / might / would be well advised to
> ③ Points 槽（换内容不换结构，任何话题通用）
>    {措施} = invest in {领域} / subsidise {服务} / impose a tax on {事物} / raise awareness of {问题}
>    {效果} = reduce the burden on {对象} / widen access to {资源} / cut emissions
> ```
> **符号**：`{ }` = 你要填的内容点；`A / B / C` = 可互相替换的固定块；🅐 = 6.5 保底 ｜ 🅑 = 7.5 主力 ｜ 🅒 = 8+ 加分。
> **铁律**：骨架必须一字不差背熟，替换只在槽内进行。**先想清楚要说什么，再选骨架。**

## T2-0 四段式总骨架（按题型）

**通用四段（任何题型都能装）**
```
第 1 段  Introduction  2 句  背景改写 + 明确立场/答题
第 2 段  Body 1        5 句  主题句 + 机制 + 例证 + 后果
第 3 段  Body 2        5 句  主题句 + 机制 + 例证 + （让步反驳）
第 4 段  Conclusion    2 句  重述立场 + 概括理由
```
**字数分配**：引言 45–55 ｜ 主体 各 95–110 ｜ 结论 30–40 ｜ **总计 265–290**。

### 按题型的段落分工

| 题型 | Body 1 | Body 2 | 结论 |
|---|---|---|---|
| Agree/Disagree（完全同意）| 理由 1 + 例证 | 理由 2 + 例证（+ 让步反驳）| 重述立场 |
| Agree/Disagree（部分同意）| `I accept that {对方} …` | `I believe that {我方} matters more …` | 重申平衡立场（+条件）|
| Discuss both views | View A 的最强理由 | View B 的最强理由 + **我的判断** | 站边 |
| Advantages & Disadvantages | 优点 2 条 | 缺点 2 条 | 概括（若问 outweigh，表态）|
| Outweigh | 我支持的一边（论证更充分）| 另一边（承认 + 指出局限）| 重申"更重" |
| Problem & Solution | 原因 1 + 原因 2 | 方案 1 + 方案 2（对应原因）| 概括 + 呼吁 |
| Two-part question | 回答第 1 问 | 回答第 2 问 | 两问各一句 |
| Positive/Negative | 为什么正面 | 承认负面 + 可缓解 | 重申总体判断 |

## T2-1 引言：背景句骨架

### 骨架 1 🅐 —— "争论存在"型（最通用）

```
The question of whether or not {题干核心从句} has been the subject of recent / heated public discussion / debate.
```
```
替换 recent: ongoing / considerable / much
替换 public discussion/debate: debate / controversy / public scrutiny / academic interest
```

### 骨架 2 🅐 —— "双方对立"型（用于双方观点题）

```
While some people argue that {立场 A}, others maintain that {立场 B}.
```
```
替换 argue: believe / claim / contend / assert / are of the opinion
替换 maintain: insist / hold / argue / point out
```

### 骨架 3 🅐 —— "日益受关注"型

```
{话题名词} has become an increasingly {形容词} issue in recent years.
```
```
形容词: controversial / pressing / contentious / significant / debated / widespread
```

### 骨架 4 🅑 —— "现象 + 数据感"型（避免空洞）

```
Recent years have seen a {形容词} {变化名词} in {现象}, and there is evidence to suggest that {进一步事实}.
         ⚠️ `there is evidence to suggest that` 语料 0 命中；语料的说法是 `the evidence suggests that`
```
```
变化名词: rise / increase / growth / decline / shift
⚠️ 反例修正法：不要写"水对生命很重要"这种事实句，要写有信息量的句子。
```

### 骨架 5 🅑 —— 强调重要性

```
{话题名词} is one of the most {形容词} {名词} facing {群体} today.
```
```
形容词: significant / serious / pressing / urgent / debated
名词:     issues / challenges / problems / concerns / considerations
群体:     modern societies / governments / young people / the workforce / humanity
```

### 骨架 6 🅑 —— "普遍认知"型

```
It is widely / commonly / generally {过去分词} that {从句}.
```
```
过去分词: believed / accepted / assumed / acknowledged / argued
```

### 骨架 7 🅒 —— 定义 + 限定范围（适合抽象题）

```
For the purposes of this essay, {关键词} can be defined as {定义}, and this definition forms the basis of the argument below.
```

### ⚠️ 背景句三不要
1. ✗ 不要写"无可争议的事实"（`Water is necessary for human life`）—— 用 `There are those who argue that` 去包装事实是**结构错配**。
2. ✗ 不要过度泛化（`Since the dawn of time, people have…`）。
3. ✗ 不要超过 1 句 —— 背景句只是垫场，立场句才是主角。

## T2-2 引言：立场句骨架

### 完全同意 / 完全不同意

```
骨架 1 🅐  Personally, I {完全同意/不同意动词} with this view.
            动词: completely agree / firmly agree / entirely agree / completely disagree / strongly disagree
骨架 2 🅐  In my opinion, {改写后的主张}, and I will explain why below.
骨架 3 🅑  I firmly believe that {主张}, on the grounds that {笼统理由}.
            替换 on the grounds that: for the simple reason that / because / since
骨架 4 🅑  I am convinced that {主张} is {形容词}.
            形容词: justified / well founded / misguided / short-sighted / mistaken
骨架 5 🅒  I would argue that {主张}, primarily because {理由}.
```

### 部分同意 / 平衡立场

```
骨架 1 🅐  While I accept that {对方合理之处}, I believe that {我方核心主张}.
骨架 2 🅐  Although there is some truth in {对方观点}, I would argue that {我方主张}.
骨架 3 🅑  To a certain extent I agree that {对方}, but only when {条件}; in most cases, {我方主张}.
骨架 4 🅑  I partly agree with this statement, since {我的限定条件}.
骨架 5 🅒  My position is a qualified one: {对方} holds true in {特定情境}, yet {我方} is the more significant factor overall.
```

### 直接回答 outweigh / positive-negative 型

```
骨架 1  In my view, the {advantages / benefits} of {现象} clearly outweigh its {disadvantages / drawbacks}.
骨架 2  I consider this to be a largely {positive / negative} development, for two main reasons.
骨架 3  On balance, I believe that {判断}, although {让步} .
```

**Points 槽：让立场句有"理由感"**
```
{笼统理由} 的通用填入词（跨话题可用）：
  it would benefit both individuals and society
  it is both fair and economically sensible
  the long-term consequences are far more significant than the short-term costs
  it addresses the root cause rather than the symptoms
  it protects the interests of those who are least able to protect themselves
```

## T2-3 引言：预告句骨架

```
骨架 1  This essay will {动词} {内容 1} before {动词-ing} {内容 2}.
          动词: examine / consider / discuss / analyse / outline
          内容: the arguments for and against {话题} / the main causes of {问题} / possible solutions
骨架 2  This essay will first {动作 1}, and then {动作 2}.
骨架 3  The following paragraphs will examine {方面 1} and {方面 2}.
骨架 4  I will begin by {动作-ing}, before turning to {方面}.
```
> **取舍建议**：前考官只用 **2 句引言**（背景 + 立场），不写预告句；另一些教材用 **3 句**（背景 + 立场 + 预告）。两种都可以，**关键是总词数不能挤掉主体段**。若时间紧张，删掉预告句。

## T2-4 主体段主题句骨架

### 第一段

```
骨架 1 🅐  Firstly, one argument in favour of {立场 / 做法} is that {从句}.
骨架 2 🅐  The main reason why I {动词} this is that {从句}.
骨架 3 🅑  The most compelling reason for {立场} is that {从句}.
骨架 4 🅑  One of the principal benefits of {做法} is {名词短语}.
骨架 5 🅑  A key factor in {现象} is {名词短语}.
骨架 6 🅒  Chief among the reasons for {立场} is {名词短语}.
```
```
替换 Firstly: First of all / To begin with / In the first place / Above all / Most importantly
```

### 第二段（不要再用 Secondly）

```
骨架 1 🅐  A further reason why {主张} is that {从句}.
骨架 2 🅐  Another argument in favour of {立场} is that {从句}.
骨架 3 🅑  Equally important is the fact that {从句}.
骨架 4 🅑  {主张} is also supported by the fact that {从句}.
骨架 5 🅑  The second consideration is {名词短语}.
骨架 6 🅒  A further consideration, which is often overlooked, is {名词短语}.
骨架 7 🅒  What is more significant, however, is {名词短语}.
```

### 让步段 / 反方段

```
骨架 1  Admittedly, {对方合理之处}. However, {反驳}.
骨架 2  It is true that {对方}. Nevertheless, {反驳}.
骨架 3  While it may be argued that {对方}, this argument overlooks {关键点}.
骨架 4  Those who oppose {做法} often claim that {对方论点}. This view, however, fails to consider {关键点}.
骨架 5  Opponents of {做法} point to {对方论据}, yet {反驳}.
骨架 6  There is, of course, a case for {对方}, namely that {论点}. Even so, {反驳}.
         ⚠️ `Even so` 在约 23 万词语料中 0 命中 —— 可用，但不是这批范文的用法（语料里用 `However` / `That said`）
```

### 用 "This + 名词" 打包上文（段内衔接神器）

```
骨架  This {名词} {动词短语}.
名词槽: argument / trend / policy / measure / approach / factor / issue / evidence / analysis / principle / process / development / change / situation / tendency
例:     This measure would be particularly effective in {场景}.
        This trend is unlikely to reverse in the near future.
        These factors combine to {结果}.
```

## T2-5 解释机制骨架（Why 层）

> 这是区分 6 分与 7 分的核心段落层：**必须解释"为什么"，不能只重复主张**。方法是连续追问 why。

```
骨架 1 🅐  This is because {原因从句}.
骨架 2 🅐  The reason for this is that {从句}.
骨架 3 🅐  This means that {结果从句}.
骨架 4 🅑  {现象} occurs largely because {原因}.
骨架 5 🅑  This can be explained by the fact that {从句}.
骨架 6 🅑  {X} stems from / derives from / arises from {来源}.
骨架 7 🅑  {X} is closely linked to / associated with {Y}.
骨架 8 🅒  The underlying cause of {现象} is {深层原因}, which in turn {进一步后果}.
骨架 9 🅒  Once {条件}, {结果} becomes almost inevitable.
骨架 10 🅒  {X} and {Y} are mutually reinforcing: {机制说明}.
```

## T2-6 因果与后果骨架

```
骨架 1 🅐  As a result, {结果}.
骨架 2 🅐  Consequently, {结果}.
骨架 3 🅐  This leads to {名词短语}.
骨架 4 🅐  Therefore, {结论}.
骨架 5 🅑  This, in turn, {动词短语}.
           例: This, in turn, places a heavy burden on public services.
骨架 6 🅑  The long-term consequence of this is {名词短语}.
骨架 7 🅑  {X} has a {形容词} effect / impact on {Y}.
           形容词: profound / detrimental / adverse / beneficial / far-reaching / lasting / negligible
            ⚠️ 其中 `profound`、`far-reaching` 语料 0 命中；实测高频的是 `detrimental`(21) / `adverse`(11) / `negative`(29)
骨架 8 🅑  The result is a {形容词} {名词}: {具体化}.
           名词: rise in / decline in / increase in / deterioration in / improvement in
骨架 9 🅒  Not only does this {后果 A}, but it also {后果 B}.
骨架 10 🅒  The consequences extend well beyond {表层范围}, affecting {更深层对象}.
骨架 11 🅒  Left unaddressed, {问题} is likely to {进一步恶化动词}.
           恶化动词: worsen / escalate / intensify / spread / become entrenched
```

### 因果链模板（把三层"为什么"写进一段）

```
{现象} {动词}. This is because {第一层原因}, which means that {第一层结果}. As a result,
{第二层结果}, and this in turn {第三层影响}. For example, {具体例证}.
```
**Points 槽（跨话题通用的"第三层影响"）**
```
对个人:      reduce people's quality of life / limit their career prospects / damage their health
            增加收入: raise household income / improve living standards
对家庭:      place a strain on family relationships / reduce the time parents spend with children
对社会:      widen the gap between rich and poor / weaken social cohesion / increase crime rates
            减轻公共财政: relieve pressure on public services / reduce the burden on taxpayers
对经济:      boost productivity / attract foreign investment / create jobs / slow economic growth
对环境:      reduce carbon emissions / deplete natural resources / damage ecosystems
对政府:      place a strain on public finances / require significant public investment
对未来:      have long-term consequences for future generations / be difficult to reverse
```

## T2-7 举例骨架

```
骨架 1 🅐  For example, {具体例子}.
骨架 2 🅐  For instance, {具体例子}.
骨架 3 🅐  A clear example of this is {名词短语}.
骨架 4 🅑  A case in point is {名词短语}.
骨架 5 🅑  This is illustrated by {名词短语}.
骨架 6 🅑  Take {例子} as an example: {说明}.
骨架 7 🅑  In countries such as {国家}, {现象说明}.
骨架 8 🅑  Recent research suggests that {研究发现} — though such findings should be treated with caution.
骨架 9 🅒  This pattern is particularly evident in {领域 / 地区}, where {具体情况}.
骨架 10 🅒  Consider the case of {对象}: {说明}.
```

### 例证的四条"合法路径"（没有真实数据时怎么写例子）

| 路径 | 骨架 | 例 |
|---|---|---|
| 一般化实例 | `In many {国家/行业}, …` | In many developing countries, families still cannot afford tertiary education. |
| 假设情境 | `If {条件}, {结果}.` | If a student has to work full-time while studying, their grades are likely to suffer. |
| 常识共识 | `It is common knowledge that…` / `Few would dispute that…` | Few would dispute that a well-educated workforce benefits the economy. |
| 研究/专家（模糊引用）| `Economists generally agree that…` / `Studies consistently show that…` | Studies consistently show that early intervention reduces long-term public costs. |

> ⚠️ **绝对不要编造精确数据**（"According to a 2019 Oxford University study, 73.5% of…"）—— 考官无法核实，但假数据的浮夸语气会伤害可信度。用上面四种模糊化路径。

## T2-8 让步与反驳骨架

```
骨架 1 🅐  Admittedly, {对方合理之处}. However, {反驳}.
骨架 2 🅐  Although {对方}, {我方}.
骨架 3 🅐  While it is true that {对方}, this does not mean that {我方结论}.
骨架 4 🅑  It could be argued that {对方}; nevertheless, {反驳}.
骨架 5 🅑  Critics may claim that {对方}, but this argument overlooks {关键点}.
骨架 6 🅑  There is some merit in {对方观点}, particularly {限定条件}. Even so, {反驳}.
         ⚠️ 同上：`Even so` 语料 0 命中
骨架 7 🅑  Even if {对方成立}, {我方仍然成立}.
           例: Even if these measures are expensive, the cost of inaction would be far higher.
骨架 8 🅒  This objection is not without force, but it is outweighed by {更强理由}.
骨架 9 🅒  Such concerns, though understandable, rest on the assumption that {错误假设}.
骨架 10 🅒  The argument that {对方} confuses {概念 A} with {概念 B}.
```

**反驳的三种"打法"**
```
① 指出反例 / 例外：        This is not the case in {情境}, where {反例}.
② 指出被忽略的因素：        This argument overlooks {被忽略因素}.
③ 承认但降级（最稳）：      These drawbacks are real but relatively minor compared with {更大的收益}.
```

## T2-9 讨论双方观点骨架

```
骨架 1 🅐  On the one hand, {观点 A}, because {理由}.
骨架 2 🅐  On the other hand, {观点 B}, since {理由}.
骨架 3 🅑  Those who support {观点 A} argue that {论点}.
骨架 4 🅑  Supporters of {观点 A} point out that {论点}.
骨架 5 🅑  Proponents of {观点 B} maintain that {论点}.
骨架 6 🅑  From the perspective of {群体}, {观点}.
骨架 7 🅒  The case for {观点 A} rests on {前提}, whereas the case for {观点 B} rests on {前提}.
骨架 8 🅒  While {观点 A} has considerable merit, {观点 B} is more persuasive, since {理由}.
```
**⚠️ 关键**：discuss 题型必须**明确站边**（可在 Body 2 末或结论）。
```
站边句：On balance, I find {A/B} the more convincing view, because {理由}.
```
**⚠️ 在 agree/disagree 题里，不要用 `Some people believe… Others argue…` 写整段** —— 那会变成 discussion essay，属于回答错任务。

## T2-10 问题解决骨架

### 原因段

```
骨架 1  One of the main causes of {问题} is {原因}.
骨架 2  {问题} is largely caused by / attributable to {原因}.
骨架 3  A major factor contributing to {问题} is {因素}.
骨架 4  {问题} arises from a combination of {因素 A} and {因素 B}.
骨架 5  At a deeper level, {问题} stems from {深层原因}.
```
```
通用原因 Points（跨话题）：
  a lack of public awareness / inadequate government regulation / the absence of clear laws
  the high cost of {替代方案} / limited access to {资源} / unequal distribution of {资源}
  rapid urbanisation / population growth / technological change / changing social attitudes
  short-term economic pressures / the profit motive / weak enforcement of existing rules
```

### 解决段

```
骨架 1 🅐  One obvious solution would be for {执行者} to {措施}.
骨架 2 🅐  {执行者} could {措施}, which would {效果}.
骨架 3 🅑  A more effective approach would be to {措施}.
骨架 4 🅑  {问题} could be tackled by {动词-ing}.
           动词: introducing / imposing / investing in / subsidising / regulating / promoting
骨架 5 🅑  {执行者} should {措施} in order to {目的}.
骨架 6 🅑  Government campaigns to raise awareness of {问题} would help to {效果}.
骨架 7 🅑  Legislation requiring {要求} would be an effective way of {目的}.
骨架 8 🅒  The most sustainable solution is to address the root cause: {根本原因}, rather than merely {治标做法}.
骨架 9 🅒  Any effective policy would need to combine {措施 A} with {措施 B}, since neither alone would suffice.
骨架 10 🅒  While individuals can contribute by {个人行动}, meaningful change requires {制度层面行动}.
```
```
执行者槽（必须写清是谁）：governments / local authorities / schools / universities / employers /
                          the media / international organisations / individuals / parents
措施动词库: invest in / subsidise / tax / ban / restrict / regulate / legislate / incentivise /
            fund / promote / launch campaigns / provide free {服务} / improve access to {资源} /
            make {事物} compulsory / raise awareness of / enforce existing laws
```
**⚠️ 高分要点**：方案必须**对应前文的原因**（原因写"成本高"→ 方案就写"补贴/降低门槛"），否则 Task Response 会被判为逻辑断裂。

## T2-11 利弊骨架

```
骨架 1 🅐  One of the main advantages of {做法} is that {从句}.
骨架 2 🅐  The greatest benefit of {做法} is {名词短语}.
骨架 3 🅐  However, {做法} also has a number of drawbacks.
骨架 4 🅑  {做法} offers considerable benefits, chief among which is {名词短语}.
骨架 5 🅑  On the positive side, {优点}; on the negative side, {缺点}.
骨架 6 🅑  The most serious disadvantage is that {从句}.
骨架 7 🅑  A further drawback is the risk that {从句}.
骨架 8 🅒  The benefits, though substantial, tend to be {形容词}, whereas the costs are {形容词}.
           形容词组合: long-term / short-term ｜ concentrated / widespread ｜ reversible / permanent
骨架 9 🅒  Weighing the two, the advantages clearly outweigh the disadvantages, since {理由}.
```

## T2-12 结论骨架

```
骨架 1 🅐  In conclusion, I firmly believe that {立场}.
骨架 2 🅐  To conclude, {重述主张}.
骨架 3 🅑  In conclusion, although {让步}, {立场}.
骨架 4 🅑  In conclusion, while there are arguments on both sides, {判断}.
骨架 5 🅑  To sum up, {概括}, and I would argue that {立场}.
骨架 6 🅑  In conclusion, the {benefits / drawbacks} of {现象} outweigh the {drawbacks / benefits}, primarily because {核心理由}.
骨架 7 🅒  In conclusion, the evidence suggests that {判断}; what matters is not whether {X}, but how {Y}.
骨架 8 🅒  On balance, then, {判断}. Provided that {条件}, {展望}.
```
**结论第二句的三种收尾**
```
① 概括理由：  This is mainly because {理由 A} and {理由 B}.
② 提出建议：  Governments should therefore {措施} before {问题} becomes more serious.
③ 展望预测：  Unless {条件}, {问题} is likely to {恶化}.
```
**⚠️ 结论禁忌**：不引入新论点、不举例、不提问、不用 `In a nutshell` 等口语表达、不要只写一句（两句更稳）。

## T2-13 高阶强调与倒装骨架

```
骨架 1 🅒  Not only does {X} {动词}, but it also {动词}.
           例: Not only does working provide you with experience, but it also improves essential skills.
骨架 2 🅒  It is {强调对象} that {从句}.
           例: It is the lack of enforcement, rather than the absence of laws, that explains this problem.
骨架 3 🅒  Only when {条件} can {结果}.
           例: Only when penalties are high enough can such behaviour be deterred.
骨架 4 🅒  Not until {时间/条件} did {主体} {动词}.
骨架 5 🅒  Were {主体} to {动词}, {结果} would {动词}.
           例: Were governments to invest in public transport, congestion would fall sharply.
骨架 6 🅒  So {形容词} is {X} that {结果}.
           例: So severe is the shortage of housing that young people can no longer afford to buy.
骨架 7 🅒  What matters most is not {X} but {Y}.
```
> **使用策略**：全篇**最多用 1–2 次**这类结构，用多了会显得刻意（band 6 的"机械"特征）。

## T2-14 对冲与限定骨架

> 原则：**没有证据时必须对冲**；**公认事实不要对冲**。

```
骨架 1 🅐  {X} may {动词} {影响对象}.
骨架 2 🅐  {X} is likely to {动词}.
骨架 3 🅐  In most cases, {判断}.
骨架 4 🅑  There is evidence to suggest that {从句}.
骨架 5 🅑  {X} tends to {动词} when {条件}.
骨架 6 🅑  It is possible that {从句}, although {限制}.
骨架 7 🅑  This is particularly true of {范围}.
骨架 8 🅑  {X} can have a {形容词} effect on {Y}.
骨架 9 🅒  {X} appears to be associated with {Y}, though the relationship is not necessarily causal.
骨架 10 🅒  To the extent that {条件}, {结论} holds.
骨架 11 🅒  This is not to suggest that {过度解读}; rather, {真实主张}.
```
```
对冲词库: may / might / could / tends to / is likely to / in most cases / for the most part /
          generally / broadly speaking / to some extent / it would appear that / arguably
```
**✗ 反向错误示例**：`Annual financial reports *might* include information from financial statements…`
—— 这是定义/机制，不是推断，用 may 反而错误。判断标准：**是"我的推断"还是"事情的机制"**。

## T2-15 连接词功能表

| 功能 | 可替换词块 | 位置/标点 |
|---|---|---|
| 并列递进 | and, moreover, furthermore, in addition, additionally, what is more, besides | 句首 + 逗号 |
| 对比 | however, nevertheless, nonetheless, on the other hand, by contrast, in contrast, whereas, while | however 句首 + 逗号；whereas 在句中 |
| 让步 | although, though, even though, despite, in spite of, admittedly, granted | although + 从句；despite + 名词 |
| 因果 | because, since, as, because of, due to, owing to, therefore, consequently, as a result, thus, hence | because + 从句；because of + 名词 |
| 举例 | for example, for instance, such as, namely, to illustrate, a case in point | such as 后接名词，不加逗号+从句 |
| 顺序 | firstly, first of all, to begin with, secondly, next, then, subsequently, finally, lastly | 段内使用 |
| 总结 | in conclusion, to conclude, to sum up, overall, on balance, in short | 结论段专用 |
| 条件 | if, unless, provided that, as long as, in the event that, should {主语} {动词} | should 倒装表条件 🅒 |
| 强调 | indeed, in fact, above all, most importantly, particularly, notably | 句中或句首 |
| 目的 | in order to, so as to, with a view to {动词-ing}, so that | in order to + 动词原形 |

**⚠️ 三条使用规则**
1. **不要每句都加连接词** —— band 6 的典型特征是"衔接机械"（mechanical）。同段内 2–3 个就够。
2. **`However` 不能像 `but` 那样连接两个分句**：✗ `X rose, however Y fell.` → ✓ `X rose. However, Y fell.` 或 `X rose, whereas Y fell.`
3. **段首不要用 `And` / `But` / `Because`**：→ `Moreover` / `However` / `Since`。

## T2-16 Task 2 通用 Points 银行

> 这是"组合拳"的第三层：当你想不出内容点时，从这里取。**所有 Points 都可跨话题使用**，只把 `{ }` 换成题目话题。

### 16.1 万能理由（十大论证角度）

| # | 角度 | 核心论点（可直接当 topic sentence 的后半截）|
|---|---|---|
| 1 | 经济 | it boosts productivity / creates jobs / reduces the burden on taxpayers |
| 2 | 公平 | it gives everyone, regardless of background, a fair chance to {目标} |
| 3 | 公共财政 | it requires substantial public investment, which may mean higher taxes |
| 4 | 个人发展 | it develops skills such as {技能}, which are essential in later life |
| 5 | 社会凝聚力 | it strengthens social cohesion and reduces inequality |
| 6 | 健康与福祉 | it improves physical and mental well-being |
| 7 | 环境 | it reduces carbon emissions / protects natural resources for future generations |
| 8 | 安全与秩序 | it deters crime / improves public safety |
| 9 | 自由与权利 | it respects individual freedom of choice / it protects vulnerable groups |
| 10 | 长期 vs 短期 | the long-term benefits far outweigh the short-term costs |

### 16.2 万能影响对象（把论点"落地"）

```
个人层:  young people / students / employees / parents / the elderly / low-income families / consumers
机构层:  schools / universities / employers / hospitals / the media / small businesses
公共层:  governments / local councils / taxpayers / public services / the economy
宏观层:  society as a whole / future generations / the environment / the labour market
```

### 16.3 万能"程度与条件"限定（让论点有分寸）

```
限定范围:  in most cases / particularly in {发展中国家 / 大城市 / 农村地区}
限定条件:  provided that {条件} / as long as {条件} / unless {条件}
限定程度:  to a large extent / to some degree / in the short term / in the long run
```

### 16.4 万能反方论点的"标准形态"

```
反方通常只有四种形态，遇到任何题目都能预判：
  ① 成本论：       it is too expensive / the money could be better spent on {更紧迫的事}
  ② 自由论：       it restricts individual freedom / people should be free to choose
  ③ 效果论：       it does not work in practice / people will find ways around it
  ④ 副作用论：     it may have unintended consequences, such as {副作用}
反驳模板：
  ① → Even if the initial cost is high, the long-term savings would be far greater.
  ② → Individual freedom must be balanced against the harm caused to others.
  ③ → This objection assumes that {假设}, but {反证/更有效做法}.
  ④ → Such risks can be managed by {措施}, whereas inaction carries its own risks.
```

### 16.5 论证深度自检：你的段落是否只有"一层"？

```
6 分段落：{主张} → {重复主张} → {举例}
7 分段落：{主张} → {机制解释} → {直接后果} → {举例} → {更深远后果/让步}
8 分段落：{主张} → {机制} → {后果链} → {条件限定（在什么情况下成立）} → {让步并击中要害} → {例证}
```
**自检方法**：把每段的**主题句**单独抄出来读一遍，如果这些句子连起来读得通、能撑起全文，说明结构合格。

## 附：跨话题"骨架复用"速查

同一套骨架 + 只换 Points，就能覆盖不同话题。以下示范「骨架不变、内容可变」：

| 骨架 | 话题 A：教育 | 话题 B：环境 | 话题 C：科技 |
|---|---|---|---|
| `The main reason why I {动词} this is that {从句}.` | …why I support free tuition is that it widens access to higher education. | …why I oppose this policy is that it shifts the cost onto ordinary consumers. | …why I welcome this trend is that it saves users considerable time. |
| `{执行者} could {措施}, which would {效果}.` | Governments could subsidise vocational training, which would reduce youth unemployment. | Governments could tax single-use plastics, which would cut waste significantly. | Schools could teach digital literacy, which would protect children from online harms. |
| `Not only does {X} {动词}, but it also {动词}.` | Not only does bilingual education improve cognitive flexibility, but it also broadens career prospects. | Not only does recycling cut landfill waste, but it also reduces the demand for raw materials. | Not only does remote work cut commuting emissions, but it also improves work-life balance. |
