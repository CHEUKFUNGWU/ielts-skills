# IELTS Task 2 话题词汇 Cheat Sheet
### 搭配 + Chunks + 论点句 ｜ 按话题 + 按功能双重索引

> **这个文件只讲 Task 2 的词汇与论点。** Task 1（图表 / 书信）的描述性语言在 `../../ielts-writing-task1/references/vocabulary.md`。
>
> **为什么 Task 2 的词汇表按"话题"组织**：Task 1 只要换着说法描述同一件事，Task 2 则要求你**对一个话题有话说**。
> 所以这里每一个词都挂在**能直接进句子的搭配**上，并且每个话题都给"论点句模板"，让你换掉 `{ }` 就能用：
> ```
> ❌ 背单词：detrimental（有害的）
> ✅ 背搭配：be detrimental to {health / the environment}
> ✅ 背模板：Excessive {X} can be detrimental to {children's mental health}.
> ```
>
> **三种查法**
> 1. **按话题查**（第 2 部分）—— 拿到题目先定位话题，直接取搭配 + 动词块 + 论点句模板 + 整段范例。
> 2. **按功能查**（第 3、4 部分）—— 想说"导致""减轻""证明""不可否认"时，去功能词族与万能 chunks 里挑。
> 3. **按语料查**（文末附录）—— 想知道内部语料中出现过哪些词时，看语料观察库。
>
> **符号**：`{ }` = 可替换内容；`🅐/🅑/🅒` = 从较简单到较复杂的表达。符号不保证对应分数。

> **证据等级与严谨性说明（请务必读这一段，它决定你该背哪些）**
>
> 本文件的内容有**三级证据等级**，按等级分开标注，以免你把"通用常用词"误当成"范文语料里真实用过的词"：
>
> | 等级 | 含义 | 在文件中的位置 |
> |---|---|---|
> | **① 内部语料观察** | 在内部收集的 Task 2 文本中出现过并附有计数；仓库当前没有原始语料和复现脚本，详见 `../../ielts-band8-vocabulary/references/methodology.md` | **附二「语料观察库」全部内容**；第 3 部分的功能词族多数 |
> | **② 系统词表** | 来自一套按 12 个话题组织、另含约 460 条 A–Z 学术词表的系统词汇教材：话题词块、释义与例句 | 第 3 部分的功能词族；第 2 部分中该词汇书覆盖的话题（People / Health / Education / Advertising / Travel / Animals / Technology / Fashion / City life / Environment / Media / Social & leisure）|
> | **③ 通用学术搭配** | 在内部语料中出现 0–2 次的候选表达。零命中不代表错误；使用前仍要检查语义、搭配和语域 | 第 2 部分其余内容 |
>
> **等级 ③ 的完整清单（语料 0 命中，最需要你知道的诚实交代）**
> ```
> zero hits:  compulsory education · urban sprawl · screen time · the digital divide
>             bear the cost of · curb emissions · the gap between rich and poor（仅 1 次）
>             address the root cause of
> 1–2 hits:   impose a ban on · juvenile delinquency · alleviate poverty
> ```
> 这些表达并不因零命中而变成错误。下面的替代表只展示内部语料中出现过的说法，不表示右边一定比左边更自然：
> ```
> compulsory education        → a compulsory part of high school programmes
> urban sprawl                → move from centre areas to suburbs / rural depopulation
> screen time                 → excessive time using technological gadgets
> bear the cost of            → shoulder the cost / pay for
> curb emissions              → reduce carbon emission(s) / minimize the use of personal vehicles
> the gap between rich and poor → widen the gap between the rich and poor
> address the root cause of   → tackle the problem of X / root causes（语料用的形式）
> ```
>
> **频次边界**：高频不等于高分。`Nowadays`、`Some people believe`、`As we all know`、`last but not least` 容易变成空泛或机械表达，但要根据具体句子判断，不设自动禁用清单。
>
> **语境检查**：`enhance`、`efficiency`、`popular`、`kids` 和 `punishment` 都可能正确。第 5 部分列出的是常见误用风险，不是单词黑名单。
>
> **关于"编数据"**：不要编造百分比或机构来源。Task 2 可以使用相关例子，包括个人经验；无法核实的数据通常不如清楚的机制解释可靠。
>
> **关于语料混用**：内部语料包含学习者习作和标为 Band 9 的文本。学习者文本适合观察常见用法和错误，不能直接视为目标答案。分数标签和作者身份目前无法在仓库内独立复核。

## 1. 笼统表达 → 更具体的候选表达

> 先检查左列用词是否真的妨碍精确表达。替换必须保留原意并符合搭配，不要为了显得高级而换词。

| 平民词 / 中式表达 | 高分替换 | 用法提示 |
|---|---|---|
| a lot of / lots of | a great deal of（不可数）｜ a considerable number of（可数）｜ a substantial amount of | 正式写作通常可具体化，但不是语法错误 |
| many people think | it is widely believed that ｜ many people would argue that | 避免 `people think` |
| good for | beneficial to ｜ conducive to ｜ advantageous to | `conducive to` 后接名词/动名词 |
| bad for | detrimental to ｜ harmful to ｜ damaging to | 三个都接 to |
| get (a skill) | acquire / gain / develop | 按宾语选择；`develop skills` 与 `acquire skills` 含义略有不同 |
| get rid of | eliminate / eradicate / remove / do away with | `eradicate` 用于问题/疾病 |
| make better | improve / enhance / upgrade / ameliorate | `enhance` 偏"提升价值"，别乱用 |
| make worse | exacerbate / aggravate / worsen / compound | `exacerbate` 不是“8 分词”；只在搭配和语气合适时使用 |
| stop / reduce | curb / curtail / restrict / mitigate / alleviate | `curb emissions` / `alleviate poverty` |
| help (v.) | assist / aid / support / facilitate | `facilitate` = 使…更容易 |
| need (v.) | require / necessitate / call for | 学术文体少用 `need` |
| important | significant / crucial / vital / pivotal / paramount | `play a pivotal role in` |
| problem | issue / challenge / difficulty / drawback | 别只用 problem |
| solve | address / tackle / resolve / remedy | `tackle the problem` |
| cause (v.) | lead to / result in / give rise to / trigger / bring about | `give rise to` 后接名词 |
| because of | owing to / due to / as a result of / on account of | `due to` 后接名词 |
| so | therefore / consequently / as a result / hence | 别用 `so` 开头 |
| But | However / Nevertheless / That said | `But` 可以置于句首；正式度和逻辑关系决定选择 |
| also | moreover / furthermore / in addition / what is more | |
| I think | In my view / I would argue that / It seems to me that | `I think` 并非错误，但重复使用可能显得单调 |
| more and more | an increasing number of / a growing proportion of | 后接复数可数名词 |
| things | （删掉，换具体名词） | `thing` 是禁词 |
| kids | children / young people / youngsters | |
| old people | the elderly / senior citizens / older adults | `the elderly` 作整体 |
| rich / poor people | affluent / wealthy ｜ low-income / disadvantaged | `the affluent` / `low-income households` |
| government | the authorities / policymakers / the state | 变换使用 |
| money | funding / finance / capital / resources | `public funding` |

## 2. 分话题词汇 / 搭配 / 论点句

> **每个话题给四样东西**
> ① **核心搭配**（Topic collocations）—— 直接搬进句子
> ② **动词 + 宾语 chunks** —— 让句子"动起来"
> ③ **论点句模板**（带 `{ }`）—— 换个话题名就能用
> ④ **范例论证** —— 一段 3 句的现成论证，可改装
>
> ⚠️ **本部分（第 2 部分）属于上文「证据等级」中的 ②/③ 级**：搭配本身都是正确、地道的英语，但**不是**逐条从范文语料里统计出来的。若你要"只用范文语料里真正出现过的表达"，请以**文末「语料实证搭配库」**为准；两者互补，不冲突。

### 2.1 教育 Education

**① 核心搭配**
```
compulsory education / free education      义务教育 / 免费教育
tertiary / higher education                高等教育
vocational training                        职业培训
the national curriculum                    国家课程
academic performance                       学业表现
extracurricular activities                 课外活动
a well-rounded education                   全面教育
lifelong learning                          终身学习
critical thinking skills                   批判性思维
rote learning                              死记硬背
equal access to education                  教育机会均等
a widening attainment gap                  成绩差距扩大
student debt / tuition fees                学生债务 / 学费
class size / the student-teacher ratio     班级规模 / 师生比
```

**② 动词 + 宾语**
```
acquire skills / knowledge                 习得技能
broaden one's horizons                     开阔视野
foster creativity / curiosity              培养创造力
impose a heavy workload on students        给学生施加沉重课业
make education accessible to {group}       让教育惠及…
raise academic standards                   提高学业标准
narrow the gap between {A} and {B}         缩小差距
equip students with {skills}               使学生具备…
sit / take an examination                  参加考试
drop out of school                         辍学
```

**③ 论点句模板**
```
A {形容词} education system is essential if {国家} is to {目标}.
  形容词: well-funded / well-rounded / inclusive / meritocratic
  目标: compete in the global economy / break the cycle of poverty / produce a skilled workforce
Access to {教育阶段} should not depend on {家庭背景 / 收入}, since {理由}.
Investing in {教育领域} is a long-term investment that pays dividends for decades.
  教育领域: early childhood education / vocational training / teacher training
```
**④ 范例论证**
> A well-funded education system is essential if a country is to produce a skilled workforce. When children from low-income families are given the same opportunities as their wealthier peers, talent is no longer wasted simply because of an accident of birth. In many developing countries, however, families still cannot afford tertiary education, and as a result a great deal of potential is never realised.

### 2.2 工作与职业 Work & Careers

**① 核心搭配**
```
job satisfaction / job security            工作满意度 / 工作保障
work-life balance                          工作与生活的平衡
career prospects / career advancement      职业前景 / 晋升
a competitive salary / remuneration        有竞争力的薪资
flexible working arrangements              弹性工作安排
remote / hybrid working                    远程 / 混合办公
a sedentary job                            久坐的工作
job-related stress / burnout               工作压力 / 职业倦怠
on-the-job training                        在职培训
a skills shortage                          技能短缺
the gender pay gap                         性别薪酬差距
a glass ceiling                            玻璃天花板（晋升壁垒）
redundancy / downsizing                    裁员
employee turnover                          员工流动率
a dead-end job                             没有前途的工作
```
**② 动词 + 宾语**
```
pursue a career in {领域}                  从事…职业
strike a balance between {A} and {B}       取得平衡
meet tight deadlines                       赶工期
climb the career ladder                    职场晋升
secure a permanent position                获得长期职位
enhance productivity / efficiency          提高生产率
place excessive demands on employees       对员工要求过度
offer generous benefits / paid leave       提供优厚福利
```
**③ 论点句模板**
```
{因素} should not be the only consideration when choosing a career, since {理由}.
  因素: salary / prestige / job security
A healthy work-life balance is more {形容词} than {对比项} in the long run.
  形容词: valuable / sustainable / conducive to productivity
  对比项: a higher salary / rapid promotion
Employers who invest in {培训} tend to be rewarded with {结果}.
  结果: greater loyalty / lower staff turnover / higher productivity
```
**④ 范例论证**
> Salary should not be the only consideration when choosing a career, since a well-paid job that leaves no time for family life is unlikely to be sustainable. Employees who are given flexible working arrangements and on-the-job training tend to be more productive and far less likely to leave, which means that investing in staff is ultimately in an employer's own interest.

**① 核心搭配**
```
technological advances / breakthroughs     技术进步
digital literacy                           数字素养
screen time                                屏幕时间
social media platforms                     社交媒体平台
online privacy / data protection           网络隐私 / 数据保护
cyberbullying / online harassment          网络霸凌
the digital divide                         数字鸿沟
artificial intelligence / automation       人工智能 / 自动化
a double-edged sword                       双刃剑
face-to-face interaction                   面对面交流
information overload                       信息过载
fake news / misinformation                 假新闻 / 错误信息
a sedentary, screen-based lifestyle        久坐、看屏幕的生活方式
```
**② 动词 + 宾语**
```
become ubiquitous / widespread             变得无处不在
revolutionise the way {people do X}        彻底改变…的方式
erode privacy / social skills              侵蚀隐私 / 社交能力
bridge / widen the digital divide          弥合 / 扩大数字鸿沟
fall victim to online fraud                成为网络诈骗受害者

**③ 论点句模板**
```
{技术} is a double-edged sword: while it {好处}, it also {坏处}.
  技术: social media / artificial intelligence / smartphones
The benefits of {技术} can only be realised if {条件}.
  条件: users are taught digital literacy / adequate safeguards are in place
{技术} has transformed the way {群体} {动作}, with profound consequences for {领域}.
  领域: education / employment / personal relationships
```
**④ 范例论证**
> Social media is very much a double-edged sword. While it allows people to maintain friendships across great distances, it also encourages constant comparison with others and can be detrimental to teenagers' self-esteem. The benefits can only be realised if schools teach digital literacy from an early age, so that young people learn to use these platforms rather than be used by them.

### 2.4 环境与气候 Environment & Climate

**① 核心搭配**
```
climate change / global warming            气候变化 / 全球变暖
greenhouse gas emissions                   温室气体排放
carbon footprint                           碳足迹
fossil fuels / renewables                  化石燃料 / 可再生能源
deforestation / habitat destruction        森林砍伐 / 栖息地破坏
air and water pollution                    空气与水污染
biodiversity loss / endangered species     生物多样性丧失 / 濒危物种
single-use plastics                        一次性塑料
waste disposal / landfill                  垃圾处理 / 填埋
sustainable development                    可持续发展
natural resources / depletion              自然资源 / 枯竭
extreme weather events                     极端天气事件
environmental degradation                  环境退化
```
**② 动词 + 宾语**
```
curb / cut emissions                       削减排放
tackle climate change                      应对气候变化
deplete natural resources                  消耗自然资源
preserve / protect natural habitats        保护自然栖息地
impose a ban on {塑料 / 排放}              禁止…
invest heavily in renewable energy         大力投资可再生能源
raise environmental awareness              提高环保意识
offset carbon emissions                    抵消碳排放
dispose of waste responsibly               负责任地处理垃圾
```
**③ 论点句模板**
```
{问题} is one of the most pressing challenges facing {群体} today.
  问题: climate change / the loss of biodiversity / air pollution
Unless {执行者} {措施}, {后果} is likely to become irreversible.
  措施: cut emissions drastically / phase out fossil fuels
Individuals can contribute by {个人行动}, but meaningful change requires {制度层面行动}.
  个人行动: reducing their own carbon footprint
  制度层面行动: legislation and large-scale investment
```
**④ 范例论证**
> Climate change is one of the most pressing challenges facing humanity today. Although individuals can reduce their own carbon footprint by using public transport and cutting down on single-use plastics, meaningful change requires government action, since only legislation and large-scale investment can phase out fossil fuels quickly enough to prevent the most severe consequences.

### 2.5 健康与生活方式 Health & Lifestyle

**① 核心搭配**
```
a sedentary lifestyle                      久坐不动的生活方式
a balanced diet                            均衡饮食
a sedentary job / an active lifestyle      久坐的工作 / 积极的生活方式
preventive medicine / preventive care      预防医学
mental health / psychological well-being   心理健康
obesity rates                              肥胖率
life expectancy                            预期寿命
the ageing population                      人口老龄化
chronic illness / lifestyle-related disease 慢性病
healthcare provision / public health spending 医疗供给 / 公共卫生支出
free healthcare at the point of use        免费医疗
waiting lists / staff shortages            候诊名单 / 人手短缺
```
**② 动词 + 宾语**
```
adopt a healthier lifestyle                养成更健康的生活方式
monitor one's daily intake of {糖/脂肪}    监控每日摄入量
suffer from {疾病}                         患有…
combat / tackle obesity                    对抗肥胖
place a strain on health services          给医疗服务造成压力
undergo treatment / surgery                接受治疗 / 手术
raise awareness of {健康风险}              提高健康风险意识
be detrimental to one's health             有害健康
be admitted into hospital                  入院
alleviate pressure on hospitals            缓解医院压力
```
**③ 论点句模板**
```
Prevention is far cheaper than cure: {预防措施} would {效果}.
  预防措施: investing in public health campaigns / subsidising healthy food
  效果: reduce the burden on hospitals / save taxpayers' money
{不良习惯} has become increasingly common among {群体}, which is likely to {后果}.
  不良习惯: a sedentary lifestyle / excessive sugar consumption
  后果: lead to higher rates of chronic illness in later life
A healthy population is a precondition for {目标}.
  目标: economic productivity / a functioning workforce
```
**④ 范例论证**
> Prevention is far cheaper than cure, and investing in public health campaigns would therefore reduce the long-term burden on hospitals. A sedentary lifestyle has become increasingly common among office workers, and this is likely to lead to higher rates of chronic illness in later life. Given that a healthy population is a precondition for economic productivity, such investment would pay for itself many times over.

### 2.6 犯罪与惩罚 Crime & Punishment

**① 核心搭配**
```
the crime rate / rates of offending         犯罪率
juvenile delinquency / young offenders      青少年犯罪
petty crime / serious offences              轻微犯罪 / 严重罪行
white-collar crime / fraud                  白领犯罪 / 诈骗
reoffending / recidivism rates              再犯率
the root causes of crime                    犯罪根源
deterrent effect                            威慑作用
rehabilitation / reform                    改造 / 改造
capital / corporal punishment               死刑 / 体罚
community service                           社区服务
the prison population / overcrowding        监狱人口 / 过度拥挤
law enforcement / the police force          执法 / 警力
surveillance cameras / CCTV                 监控摄像头
```
**② 动词 + 宾语**
```
deter potential offenders                   威慑潜在犯罪者
tackle the root causes of crime             解决犯罪根源
impose / hand down a sentence               判刑
rehabilitate offenders                      改造罪犯
reoffend / relapse into crime               再次犯罪
flout the law                               藐视法律
enforce existing legislation                执行现行法律
reduce reoffending rates                    降低再犯率
deter people from {动作}                    阻止人们…
```
**③ 论点句模板**
```
Punishment alone is unlikely to reduce crime unless {条件}.
  条件: the root causes, such as poverty and poor education, are addressed
{措施} would be more effective than {对比措施} in reducing reoffending.
  措施: rehabilitation programmes / education in prisons
  对比措施: longer prison sentences
The most effective deterrent is not {严厉惩罚} but {确定性} — {说明}.
  说明: offenders must believe they will be caught
```
**④ 范例论证**
> Punishment alone is unlikely to reduce crime unless the root causes, such as poverty and poor education, are addressed. Rehabilitation programmes that teach prisoners a trade have been shown to lower reoffending rates far more effectively than simply lengthening sentences, because they give former offenders a realistic alternative to crime.

Beyond a certain point, additional income contributes remarkably little to life satisfaction, whereas close relationships and meaningful work continue to do so throughout a person's life. This suggests that societies which measure progress purely in economic terms may be missing much of what makes life worth living.

## 5. 高风险用法清单（结合语境判断）

> 本节列出常见语域、搭配或强度风险。不要把任何单词视为自动扣分项。

### 5.1 正式议论文中通常需要调整
```
kids → children               a lot of → many / a great deal of
things → （换具体名词）        stuff → （换具体名词）
gonna / wanna → going to / want to
don't / can't / it's → do not / cannot / it is
etc. → （写出具体项目）        & → and
! ? → .（议论文不用感叹号与问号）
In a nutshell → In conclusion
Last but not least → Finally
Nowadays（句首）→ In recent years / At present
```
> `Nowadays` 并非错误。只有在它没有提供有用时间信息，或被机械用作开头时才需要删除或具体化。

### 5.2 慎用（要么搭配难，要么语气过重）
| 词 | 问题 | 更安全的选择 |
|---|---|---|
| `plummet / plunge / rocket` | 本身含"剧烈"，**不能再加副词** | fell sharply / rose dramatically |
| `enhance` | 被 band 9 范文作者点名为"最常被误用的词"，偏广告语域 | improve / strengthen |
| `utilise` | 显得刻意 | use |
| `plethora` | 用错褒贬（多指"过多"） | a wide range of / an abundance of |
| `pernicious` | 文学化 | harmful / damaging |
| `myriad` | 搭配易错（`a myriad of` vs `myriad`） | a wide range of |
| `penury / indigence` | 过于古雅 | extreme poverty |
| `welter / hodgepodge` | 语域偏低或过时 | a confusing mix of |
| `it is undeniable that` | 语气过强，容易武断 | it is widely accepted that |
| `These people are completely wrong` | 学术失礼 | However, it might be the case that… |
| `putrid / despicable / absurd` | 情绪化评价 | undesirable / questionable |
| `can't be denied` | 口语化 | cannot be denied |
| `solve the problem completely` | 绝对化 | go a long way towards solving |
