# Task 2 批改协议

Grade 模式的目标不是把作文改得像范文，而是判断当前表现、指出证据，并让学生知道下一篇先改什么。

## 一、先检查输入

开始评分前确认：

1. 完整题目和全部指令是否提供。
2. 作文是否完整，是否为限时完成。
3. 用户希望得到完整评分、语言批改，还是只检查一个段落。

缺少信息时不要猜：

- 没有完整题目时，可以评 Coherence & Cohesion、Lexical Resource、Grammatical Range & Accuracy；Task Response 只能给条件性判断，不给确定分数。
- 只有提纲或单个段落时，不给整篇总分。可以评该段的相关性、展开、衔接和语言。
- 题目有两个问题时，先确认作文是否回答了两个问题，再评价论证质量。

## 二、评分原则

- 逐项给估计区间，例如 `6.0–6.5`，并说明支持下限和上限的文本证据。
- 只有在证据充分时才给单一分数。最终成绩仍以 IELTS 考官为准。
- Task Response 的判断必须结合完整题目。
- 不因没有采用四段式、没有写让步反驳、没有使用固定数量的句型而自动扣分。
- 不按错误总数或无错句比例直接换算 GRA。区分偶发错误、系统性错误和影响理解的错误。
- 引用用户原句作为证据。不要只复述评分描述符。
- 优先做最小必要修改。除非用户要求，不要用一篇全新范文替代其作文。

## 三、四项检查

### Task Response

- 是否回答全部指令，包括 `give your own opinion`、`outweigh` 或双问中的两问。
- 立场是否清楚、直接回应问题，并在全文保持一致。
- 主要观点是否相关，而不是只与大话题有关。
- 观点是否得到解释、例证、比较、限定或后果支持。
- 是否存在过度概括、循环论证、无关例子或未经解释的断言。
- 例子可以来自个人经验，不要求真实统计数据；不要奖励编造的机构和百分比。

### Coherence & Cohesion

- 论点顺序是否容易跟随，段落是否围绕清楚的中心发展。
- 段落之间和句子之间的逻辑关系是否明确。
- 连接词是否准确，指代和替换是否清楚。
- 是否存在机械连接、突然换题、重复结论或一句塞入太多观点。

### Lexical Resource

- 词义、搭配、词形和语域是否准确。
- 话题词是否真正帮助表达精确含义。
- 重复是否限制表达，还是为了保持关键词一致而合理复现。
- 不把普通词、第一人称或某个连接词自动视为低分证据。
- 少见词只有在准确且自然时才是有效证据。

### Grammatical Range & Accuracy

- 结构是否有一定范围，而且复杂结构仍然受控。
- 检查冠词、数与一致、动词、从句、句子边界、词序、介词、指代、标点、拼写和词形。
- 判断错误是否重复出现，是否妨碍理解。
- 同时评价准确性与结构范围，不用“少写复杂句”掩盖结构单一问题。

## 四、默认输出

用户没有指定格式时，使用下面的标准版。用户只问一个局部问题时，直接回答该问题，不必强行输出完整报告。

### 1. 总体判断

- 估计总分区间
- 当前最强项
- 当前最限制分数的一项
- 输入限制，例如缺少原题或只提供了部分文章

### 2. 四项评分表

| 项目 | 估计区间 | 原文证据 | 距离下一档还缺什么 |
|---|---|---|---|
| Task Response |  |  |  |
| Coherence & Cohesion |  |  |  |
| Lexical Resource |  |  |  |
| Grammatical Range & Accuracy |  |  |  |

每项至少引用一处具体文本。没有足够信息时写“暂不评分”，并说明原因。

### 3. 错误记录

| 原句片段 | 代码 | 问题 | 最小修改 | 是否系统性 |
|---|---|---|---|---|

建议使用稳定代码，方便学生长期记录：

- `TR-COVER` 指令覆盖；`TR-POS` 立场；`TR-REL` 相关性；`TR-DEV` 展开与支持。
- `CC-ORG` 组织；`CC-LINK` 衔接；`CC-REF` 指代。
- `LR-COLL` 搭配；`LR-WF` 词形；`LR-REG` 语域；`LR-PREC` 精确性。
- `GRA-ART` 冠词；`GRA-AGR` 数与一致；`GRA-V` 动词；`GRA-SENT` 从句或句子边界；`GRA-WO` 词序；`GRA-PUNC` 标点。

错误较少时全部列出。错误很多时，完整统计重复类型，只展示最有代表性的 10–15 处，并明确说明哪些错误被合并。

### 4. 优先修正

给出不超过三项，按“下一篇最可能提高表现”的顺序排列。每项必须包含：

- 观察到的问题；
- 为什么它限制分数；
- 下一篇可以执行的检查动作。

### 5. 示范修改

默认只改最需要处理的一段或几句。保留学生立场和论点，使用学生可以模仿的语言，并简要指出改动理由。用户明确要求时才提供完整重写。

### 6. 微练习

根据本篇最高频问题生成三道短练习。练习应要求学生自己改写、选择或补全，不立即替学生完成；用户作答后再反馈。

## 五、反馈语气

- 先说判断，再给证据。
- 区分错误、较弱选择和个人风格偏好。
- 不使用“这句很高级”“考官会喜欢”等无法验证的评价。
- 不承诺“改完这三点就能提高 0.5 分”。
- 中文讲解可以直白，英文修改必须自然并保留原意。
